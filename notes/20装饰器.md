# Python3 装饰器(Decorator)笔记


## 一、什么是装饰器

装饰器（decorator）是 Python 中的一种**高级功能**，用于在不修改原函数代码的前提下，动态扩展函数或类的功能。

### 核心理解

| 要点 | 说明 |
|------|------|
| **本质** | 装饰器本身是一个**函数**，接收一个函数作为参数，返回一个新的函数（通常是对原函数的增强版本） |
| **语法糖** | 使用 `@decorator_name` 语法应用在函数或方法定义之前 |
| **等价写法** | `@decorator` 等同于 `target_function = decorator(target_function)` |

### 为什么需要装饰器

```python
# 没有装饰器：需要在每个函数中重复写日志代码
def func1():
    print("开始执行 func1")
    # 核心逻辑
    print("结束执行 func1")

def func2():
    print("开始执行 func2")
    # 核心逻辑
    print("结束执行 func2")
```

```python
# 使用装饰器：一次定义，到处复用
@log_decorator
def func1():
    # 核心逻辑
    pass

@log_decorator
def func2():
    # 核心逻辑
    pass
```


## 二、基本语法

### 2.1 装饰器的结构

装饰器的核心思想是：**用一个函数"包装"另一个函数**。

```python
def decorator_function(original_function):
    def wrapper(*args, **kwargs):
        # 调用前执行的代码
        print("执行前")
        result = original_function(*args, **kwargs)  # 调用原函数
        # 调用后执行的代码
        print("执行后")
        return result
    return wrapper

@decorator_function
def target_function():
    print("原函数执行")
```

### 2.2 执行流程解析

| 步骤 | 说明 |
|------|------|
| ① 定义 `decorator_function` | 装饰器函数，接收原函数作为参数 |
| ② 定义 `wrapper` | 包装函数，真正被执行 |
| ③ `@decorator_function` | 将原函数替换为包装函数 |
| ④ 调用 `target_function()` | 实际执行的是 `wrapper()` |

### 2.3 完整实例

```python
def my_decorator(func):
    def wrapper():
        print("函数执行前")
        func()
        print("函数执行后")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
# 输出：
# 函数执行前
# Hello!
# 函数执行后
```


## 三、处理带参数的函数

如果原函数有参数，需要在 `wrapper` 中使用 `*args` 和 `**kwargs` 来接收任意参数：

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("执行前")
        func(*args, **kwargs)   # 原封不动传递参数
        print("执行后")
    return wrapper

@my_decorator
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")
# 输出：
# 执行前
# Hello, Alice!
# 执行后
```


## 四、带参数的装饰器（装饰器工厂）

当装饰器本身需要接收参数时，需要在外层再包一层函数：

```python
def repeat(num_times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(num_times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()
# 输出：
# Hello!
# Hello!
# Hello!
```

> **理解**：`repeat(3)` 返回 `decorator` 函数，然后 `@decorator` 再装饰 `say_hello`。


## 五、类装饰器

装饰器不仅可以作用于函数，也可以作用于类。

### 5.1 函数形式的类装饰器

```python
def log_class(cls):
    class Wrapper:
        def __init__(self, *args, **kwargs):
            self.wrapped = cls(*args, **kwargs)
        def __getattr__(self, name):
            return getattr(self.wrapped, name)
        def display(self):
            print("调用前")
            self.wrapped.display()
            print("调用后")
    return Wrapper

@log_class
class MyClass:
    def display(self):
        print("原方法")

obj = MyClass()
obj.display()
# 输出：
# 调用前
# 原方法
# 调用后
```

### 5.2 类形式的类装饰器（单例模式）

```python
class SingletonDecorator:
    def __init__(self, cls):
        self.cls = cls
        self.instance = None

    def __call__(self, *args, **kwargs):
        if self.instance is None:
            self.instance = self.cls(*args, **kwargs)
        return self.instance

@SingletonDecorator
class DatabaseConnection:
    def __init__(self):
        print("创建数据库连接")

# 两次调用返回同一个实例
conn1 = DatabaseConnection()  # 打印：创建数据库连接
conn2 = DatabaseConnection()  # 不打印，直接返回已有实例
print(conn1 is conn2)  # True
```


## 六、多个装饰器堆叠

一个函数可以同时使用多个装饰器，执行顺序为**从下往上**（先装饰最内层的）：

```python
@decorator_a
@decorator_b
def func():
    pass

# 等价于：
# func = decorator_a(decorator_b(func))
```


## 七、内置装饰器

Python 提供了一些内置装饰器：

| 装饰器 | 用途 |
|--------|------|
| `@staticmethod` | 定义静态方法 |
| `@classmethod` | 定义类方法 |
| `@property` | 将方法转换为属性访问 |


## 八、常见应用场景

| 场景 | 说明 |
|------|------|
| **日志记录** | 记录函数调用信息、参数和返回值 |
| **性能统计** | 统计函数执行时间 |
| **权限控制** | 限制函数访问权限 |
| **缓存** | 缓存函数结果，提高性能 |
| **事务管理** | 自动提交/回滚数据库事务 |

### 示例：性能统计装饰器

```python
import time

def runtime(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"函数 {func.__name__} 运行时间：{end - start:.4f}秒")
        return result
    return wrapper

@runtime
def slow_function():
    time.sleep(1)
    return "完成"

slow_function()  # 输出：函数 slow_function 运行时间：1.0002秒
```


## 九、重点总结

| 知识点 | 要点 |
|--------|------|
| **本质** | 装饰器是接收函数、返回函数的高阶函数 |
| **语法** | `@decorator_name` 放在函数定义前 |
| **等价写法** | `func = decorator(func)` |
| **带参数函数** | `wrapper` 中使用 `*args, **kwargs` |
| **带参数装饰器** | 三层嵌套：外层接收参数，中层接收函数，内层接收原函数参数 |
| **类装饰器** | 接收类作为参数，返回修改后的类 |
| **堆叠** | 多个装饰器从下往上执行 |
| **应用** | 日志、性能、权限、缓存等 |

### 场景描述

你正在开发一个 Web API 服务，需要为接口函数统一添加**日志记录**、**性能监控**、**权限验证**和**缓存**功能。利用装饰器可以优雅地实现这些横切关注点（AOP）。


### 具体要求

**1. 基础装饰器 —— 日志记录**

编写装饰器 `log_decorator`：
- 打印 `"调用函数：[函数名]，参数：[args], [kwargs]"`
- 调用原函数并获取返回值
- 打印 `"返回值：[返回值]"`
- 返回原函数的返回值

**2. 处理带参数的函数**

将 `log_decorator` 改造为支持任意参数（使用 `*args, **kwargs`），然后装饰以下函数：

```python
def add(a, b):
    return a + b

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"
```

**3. 带参数的装饰器 —— 权限控制**

编写装饰器工厂 `require_permission(level)`：
- 接收权限等级参数（如 `"admin"`、`"user"`）
- 定义内部装饰器，检查当前用户权限（模拟：定义一个全局变量 `current_user_permission = "user"`）
- 如果权限不足，打印 `"权限不足！需要 [level] 权限"` 并返回 `None`
- 权限足够则正常执行函数

**4. 类装饰器 —— 接口缓存**

编写类装饰器 `CacheDecorator`：
- 在 `__init__` 中接收被装饰的类
- 在 `__call__` 中实现缓存逻辑：使用字典 `_cache` 存储 `(参数) → 返回值`
- 如果参数已存在缓存，直接返回缓存值并打印 `"从缓存获取结果"`
- 否则调用原函数，存入缓存，返回结果

**5. 多个装饰器堆叠**

定义一个函数 `get_user_info(user_id)`，同时使用：
- `@log_decorator`（日志）
- `@require_permission("admin")`（权限，使用 `current_user_permission = "user"` 测试）
- `@CacheDecorator`（缓存）

观察多个装饰器的执行顺序和效果。
