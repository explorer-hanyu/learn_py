# Python3 Socket（套接字）编程笔记

## 一、Socket 概述

**Socket（套接字）** 是应用程序与网络之间的接口，使主机间或同一台计算机上的进程间可以通讯。Python 提供两个级别的网络服务：

- **低级别网络服务**：支持基本的 Socket，提供标准 BSD Sockets API，可访问底层操作系统 Socket 接口的全部方法（`socket` 模块）。
- **高级别网络服务**：模块 `SocketServer`，提供服务器中心类，可简化网络服务器的开发（`socketserver` 模块）。


## 二、socket() 函数

创建套接字的语法：

```python
socket.socket([family[, type[, proto]]])
```

| 参数 | 说明 | 常用取值 |
|------|------|----------|
| `family` | 套接字家族 | `AF_INET`（IPv4）、`AF_UNIX`（Unix域） |
| `type` | 套接字类型 | `SOCK_STREAM`（TCP）、`SOCK_DGRAM`（UDP） |
| `proto` | 协议号 | 一般不填，默认 0 |

> 日常使用 `AF_INET` + `SOCK_STREAM`（TCP）覆盖 99% 的场景。


## 三、Socket 对象常用方法

### 3.1 服务器端方法

| 方法 | 描述 |
|------|------|
| `s.bind(address)` | 绑定地址（host, port）到套接字。`AF_INET` 下以元组表示 |
| `s.listen(backlog)` | 开始 TCP 监听。`backlog` 指定拒绝连接前可挂起的最大连接数，至少为 1，常用 5 |
| `s.accept()` | 被动接受 TCP 客户端连接，**阻塞式**等待连接到来。返回 `(conn, addr)` 元组 |

### 3.2 客户端方法

| 方法 | 描述 |
|------|------|
| `s.connect(address)` | 主动初始化 TCP 服务器连接，地址格式为元组 `(hostname, port)`，出错抛出 `socket.error` |
| `s.connect_ex(address)` | `connect()` 的扩展版本，出错时**返回错误码**而非抛出异常 |

### 3.3 数据传输方法

| 方法 | 描述 |
|------|------|
| `s.recv(bufsize)` | 接收 TCP 数据，以字符串形式返回，`bufsize` 指定最大数据量 |
| `s.send(string)` | 发送 TCP 数据，返回**实际发送的字节数**，可能小于 `string` 大小 |
| `s.sendall(string)` | 完整发送 TCP 数据，返回前尝试发送所有数据，成功返回 `None`，失败抛异常 |
| `s.recvfrom(bufsize)` | 接收 UDP 数据，返回 `(data, address)` |
| `s.sendto(data, address)` | 发送 UDP 数据到指定地址，返回发送字节数 |

### 3.4 公共方法

| 方法 | 描述 |
|------|------|
| `s.close()` | 关闭套接字 |
| `s.getpeername()` | 返回连接套接字的**远程地址** `(ipaddr, port)` |
| `s.getsockname()` | 返回套接字**自己的地址** `(ipaddr, port)` |
| `s.settimeout(timeout)` | 设置套接字操作超时期，`None` 表示无超时期 |
| `s.gettimeout()` | 返回当前超时期的值 |
| `s.setblocking(flag)` | `flag=False` 为非阻塞模式，`True` 为阻塞模式（默认） |
| `s.makefile()` | 创建一个与该套接字关联的文件对象 |


## 四、简单 TCP 实例

### 4.1 服务端

```python
import socket
import sys

# 创建 socket 对象
serversocket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 获取本地主机名
host = socket.gethostname()
port = 9999

# 绑定端口
serversocket.bind((host, port))

# 设置最大连接数，超过后排队
serversocket.listen(5)

while True:
    # 建立客户端连接
    clientsocket, addr = serversocket.accept()
    print("连接地址: %s" % str(addr))

    msg = '欢迎访问菜鸟教程！' + "\r\n"
    clientsocket.send(msg.encode('utf-8'))
    clientsocket.close()
```

### 4.2 客户端

```python
import socket
import sys

# 创建 socket 对象
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 获取本地主机名
host = socket.gethostname()
port = 9999

# 连接服务，指定主机和端口
s.connect((host, port))

# 接收小于 1024 字节的数据
msg = s.recv(1024)

s.close()

print(msg.decode('utf-8'))
```


## 五、TCP 与 UDP 的区别

| 对比项 | TCP (`SOCK_STREAM`) | UDP (`SOCK_DGRAM`) |
|--------|---------------------|---------------------|
| 连接方式 | 面向连接，需三次握手 | 无连接 |
| 可靠性 | 可靠传输，数据有序 | 不可靠，可能丢包乱序 |
| 传输方式 | `send()` / `recv()` | `sendto()` / `recvfrom()` |
| 适用场景 | 文件传输、网页浏览、聊天 | 视频流、DNS查询、广播 |
| 服务器流程 | `bind` → `listen` → `accept` | `bind` → 直接 `recvfrom` |


## 六、并发处理与异常管理

### 6.1 多线程并发服务器

服务器需同时处理多个客户端时，可使用 `threading` 模块为每个连接创建线程：

```python
import socket
import threading

def handle_client(conn, addr):
    print(f"连接来自：{addr}")
    try:
        while True:
            data = conn.recv(1024)
            if not data:
                break
            conn.sendall(data)
    finally:
        conn.close()

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('', 9999))
server.listen(5)

while True:
    conn, addr = server.accept()
    t = threading.Thread(target=handle_client, args=(conn, addr))
    t.start()
```

### 6.2 常见 Socket 异常

| 异常 | 含义 |
|------|------|
| `ConnectionRefusedError` | 服务器未在指定端口监听 |
| `ConnectionResetError` | 连接被对端重置 |
| `BrokenPipeError` | 向已关闭的连接写入数据 |
| `TimeoutError` / `socket.timeout` | 操作超时 |
| `ConnectionAbortedError` | 连接尝试被对端中止 |

使用 `try...except` 捕获并妥善处理。


## 七、SSL/TLS 加密通信

使用 `ssl` 模块为 Socket 添加加密层，保护数据传输安全：

```python
import socket
import ssl

# 服务端
context = ssl.SSLContext(ssl.PROTOCOL_TLS_SERVER)
context.load_cert_chain(certfile="server.crt", keyfile="server.key")

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
    sock.bind(('localhost', 8443))
    sock.listen(5)
    with context.wrap_socket(sock, server_side=True) as ssock:
        conn, addr = ssock.accept()
        # 使用 conn 进行加密通信
```


## 八、常见错误排查

| 错误 | 可能原因 |
|------|----------|
| `Address already in use` | 端口被占用，可设置 `SO_REUSEADDR` 选项 |
| `ConnectionRefusedError` | 服务器未启动或端口错误 |
| `TimeoutError` | 网络不通或服务器无响应，可设置 `settimeout()` |
| 绑定低端口失败 | 低端口（<1024）通常需要管理员权限 |


## 九、重点总结

| 知识点 | 要点 |
|--------|------|
| **Socket 创建** | `socket.socket(AF_INET, SOCK_STREAM)` |
| **服务器流程** | `bind` → `listen` → `accept` → `recv`/`send` → `close` |
| **客户端流程** | `connect` → `send`/`recv` → `close` |
| **TCP vs UDP** | TCP 面向连接可靠，UDP 无连接快速 |
| **并发处理** | 多线程 / `socketserver` 框架 |
| **异常处理** | 捕获 `ConnectionRefusedError`、`TimeoutError` 等 |
| **加密通信** | `ssl.wrap_socket()` 或 `SSLContext` |
| **关键方法** | `sendall()` 确保完整发送，`settimeout()` 控制超时 |

## 任务：多客户端聊天室

编写一个基于 TCP Socket 的**多客户端聊天室**，包含**服务端**和**客户端**两个程序，支持多个客户端同时在线并互相收发消息。

> 本练习覆盖：Socket 创建、`bind`/`listen`/`accept`/`connect`、`sendall`/`recv`、多线程并发、异常处理、`settimeout`


### 场景描述

开发一个命令行聊天室：多个客户端连接到服务器后，任意客户端发送的消息会被**广播**给所有其他在线客户端。客户端可以随时输入 `quit` 退出。


### 具体要求

**1. 聊天室服务端（`chat_server.py`）**

- 创建 TCP Socket，绑定 `('', 9999)`，监听 5 个连接
- 维护一个**在线客户端列表** `clients`（存储 `conn` 对象）
- 为每个新连接启动一个**独立线程**处理该客户端
- 线程函数 `handle_client(conn, addr)`：
  - 接收客户端消息，使用 `try...except` 捕获 `ConnectionResetError`
  - 如果收到空数据或 `"quit"`，从在线列表移除该客户端并关闭连接
  - 否则将消息**广播**给所有其他在线客户端（格式：`[客户端地址]: 消息内容`）
- 主循环中 `accept()` 新连接并启动线程

**2. 聊天室客户端（`chat_client.py`）**

- 创建 TCP Socket，连接到 `('localhost', 9999)`
- 启动一个**独立线程**持续接收服务器广播的消息并打印
- 主线程循环读取用户输入，使用 `sendall()` 发送给服务器
- 输入 `"quit"` 时退出程序
- 使用 `try...except` 捕获 `ConnectionRefusedError`（服务器未启动时）
