# Python3 类型注解（Type Hints）笔记

## 一、什么是类型注解

类型注解（Type Hints）是一种为代码添加 **"说明标签"** 的技术，明确地指出变量、函数参数和返回值应该是什么数据类型。

> **核心目的**：
> - **提高代码可读性**：让他人（以及未来的你）一眼就能看懂代码的意图
> - **便于静态检查**：在运行代码前，通过工具发现潜在的类型错误
> - **增强 IDE 支持**：让代码编辑器提供更准确的自动补全和提示

### 为什么需要类型注解？

Python 是动态类型语言——不需要提前声明变量的类型，解释器会在运行时自动推断。这虽然灵活，但也带来了问题：

| 问题 | 说明 |
|------|------|
| 代码难以理解 | 看到一个函数时，不清楚应该传入什么类型的数据 |
| 隐藏的 bug | 可能不小心传入了错误类型，直到运行时才报错 |
| 开发效率低 | IDE 无法提供准确的代码提示和补全 |


## 二、基础语法

### 2.1 变量注解（Python 3.6+）

```python
# 没有类型注解
name = "Alice"
age = 30
is_student = False
scores = [95, 88, 91]

# 有类型注解
name: str = "Alice"           # 注解为字符串
age: int = 30                 # 注解为整数
is_student: bool = False      # 注解为布尔值
scores: list = [95, 88, 91]   # 注解为列表
```

> `name: str` 读作 **"变量 name 的类型是 str"**。

### 2.2 函数注解

在函数参数后加 `: 类型`，在括号后加 `-> 返回值类型`。

```python
# 没有类型注解
def greet(first_name, last_name):
    full_name = first_name + " " + last_name
    return "Hello, " + full_name

# 有类型注解
def greet(first_name: str, last_name: str) -> str:
    full_name = first_name + " " + last_name
    return "Hello, " + full_name
```

**解读**：
- `first_name: str`：参数 `first_name` 应该是字符串
- `last_name: str`：参数 `last_name` 应该是字符串
- `-> str`：函数执行后会返回一个字符串

### 2.3 参数默认值 + 类型注解

可以同时使用类型注解和默认值：

```python
def say_hello(name: str, times: int = 1) -> str:
    """向某人问好指定次数"""
    return " ".join([f"Hello, {name}!"] * times)

print(say_hello("Bob"))        # Hello, Bob!
print(say_hello("Alice", 3))   # Hello, Alice! Hello, Alice! Hello, Alice!
```


## 三、复杂类型注解（typing 模块）

基本的 `str`、`int`、`list` 很好用，但如果想表达 **"一个由整数组成的列表"**，就需要 `typing` 模块。

### 3.1 容器类型

```python
from typing import List, Dict, Tuple, Set

# List[int] 表示只包含整数的列表
numbers: List[int] = [1, 2, 3, 4, 5]

# Dict[str, int] 表示键为字符串、值为整数的字典
student_scores: Dict[str, int] = {"Alice": 95, "Bob": 88}

# Tuple[int, str, bool] 表示包含整数、字符串、布尔值的元组
person_info: Tuple[int, str, bool] = (25, "Alice", True)

# Set[str] 表示只包含字符串的集合
unique_names: Set[str] = {"Alice", "Bob", "Charlie"}
```

### 3.2 可选类型（Optional）

当值**可能是某种类型，也可能是 `None`** 时使用：

```python
from typing import Optional

def find_student(name: str) -> Optional[str]:
    """根据名字查找学生，可能找到也可能返回 None"""
    students = {"Alice": "A001", "Bob": "B002"}
    return students.get(name)  # 可能返回字符串或 None

# Optional[str] 等价于 Union[str, None]
```

### 3.3 联合类型（Union）

当值**可能是多种类型之一**时使用：

```python
from typing import Union, List

def process_input(data: Union[str, int, List[int]]) -> None:
    """处理可能是字符串、整数或整数列表的输入"""
    if isinstance(data, str):
        print(f"字符串: {data}")
    elif isinstance(data, int):
        print(f"整数: {data}")
    elif isinstance(data, list):
        print(f"列表: {data}")

process_input("hello")      # 字符串: hello
process_input(42)           # 整数: 42
process_input([1, 2, 3])    # 列表: [1, 2, 3]
```


## 四、类型检查工具

### 4.1 Mypy（最流行的 Python 类型检查器）

**安装**：
```bash
pip install mypy
```

**使用**：
```bash
mypy example.py
```

**示例**：
```python
# example.py
def add_numbers(a: int, b: int) -> int:
    return a + b

result = add_numbers("5", "3")  # 这里有问题！传入了字符串
```

运行 `mypy example.py` 会输出：
```
example.py:4: error: Argument 1 to "add_numbers" has incompatible type "str"; expected "int"
example.py:4: error: Argument 2 to "add_numbers" has incompatible type "str"; expected "int"
Found 2 errors in 1 file (checked 1 source file)
```

### 4.2 IDE 实时检查

现代 IDE（如 VS Code、PyCharm）都内置了类型检查支持：
- **错误高亮**：类型不匹配的代码会被标记出来
- **智能提示**：输入代码时会显示参数和返回值的类型信息
- **自动补全**：基于类型信息提供更准确的代码补全建议


## 五、最佳实践

| 实践 | 说明 |
|------|------|
| **渐进式采用** | 从新代码开始使用，逐步为重要的旧代码添加注解 |
| **保持一致性** | 在项目中保持统一的注解风格 |
| **避免过度注解** | 过于明显的类型不需要注解（如 `x: int = 5`） |
| **为公共接口添加注解** | 为复杂逻辑或公共接口添加注解 |
| **处理第三方库** | 查看类型存根文件（`types-packageName`），或使用 `Any` 类型绕过检查 |


## 六、常见问题

| 问题 | 回答 |
|------|------|
| **类型注解会影响性能吗？** | 不会。类型注解在运行时会被忽略，只用于静态分析和开发工具。 |
| **必须使用类型注解吗？** | 不强制。Python 仍然是动态类型语言，类型注解是可选的。但强烈推荐使用，特别是大型项目。 |
| **如果注解错了会怎么样？** | 类型检查器会报错，但程序仍然可以运行。注解只是 **"提示"** 而不是 **"强制"**。 |


## 七、类型注解速查表

| 场景 | 语法 | 示例 |
|------|------|------|
| 变量注解 | `变量: 类型 = 值` | `name: str = "Alice"` |
| 函数参数 | `参数: 类型` | `def greet(name: str):` |
| 函数返回值 | `-> 类型` | `def greet() -> str:` |
| 列表（指定元素类型） | `List[类型]` | `numbers: List[int]` |
| 字典（指定键值类型） | `Dict[键类型, 值类型]` | `scores: Dict[str, int]` |
| 元组（指定各元素类型） | `Tuple[类型1, 类型2, ...]` | `info: Tuple[int, str]` |
| 集合（指定元素类型） | `Set[类型]` | `names: Set[str]` |
| 可选类型 | `Optional[类型]` | `Optional[str]` |
| 联合类型 | `Union[类型1, 类型2, ...]` | `Union[str, int]` |

## 任务：学生成绩处理系统（类型注解专项练习）

编写一个名为 `typed_student_system.py` 的程序，为现有代码**添加完整的类型注解**，并**使用 Mypy 进行类型检查**。

> 本练习覆盖：变量注解、函数参数/返回值注解、`List`/`Dict`/`Optional`/`Union` 等复杂类型注解、类型检查工具的使用


### 场景描述

你拿到了一份**没有类型注解**的学生成绩处理代码，需要为所有函数和变量添加正确的类型注解，然后运行 Mypy 验证类型正确性。


### 具体要求

**1. 为以下代码添加完整的类型注解**

```python
# ========== 原始代码（无类型注解）==========
def calculate_average(scores):
    """计算成绩列表的平均分"""
    if not scores:
        return None
    return sum(scores) / len(scores)

def get_student_info(student_id, students_db):
    """根据学号查找学生信息"""
    return students_db.get(student_id)

def process_grades(grade_data):
    """处理成绩数据，返回统计结果"""
    if not grade_data:
        return {}
    total = 0
    count = 0
    for student in grade_data:
        total += student["score"]
        count += 1
    return {
        "average": total / count,
        "count": count,
        "max": max(s["score"] for s in grade_data),
        "min": min(s["score"] for s in grade_data),
    }

def format_report(stats, title):
    """格式化统计报告"""
    if stats is None:
        return "无数据"
    report = f"=== {title} ===\n"
    report += f"人数: {stats['count']}\n"
    report += f"平均分: {stats['average']:.2f}\n"
    report += f"最高分: {stats['max']}\n"
    report += f"最低分: {stats['min']}\n"
    return report

# 测试数据
students = [
    {"name": "Alice", "score": 95},
    {"name": "Bob", "score": 88},
    {"name": "Charlie", "score": 92},
]
scores = [95, 88, 92]
student_db = {"S001": {"name": "Alice", "score": 95}}

avg = calculate_average(scores)
info = get_student_info("S001", student_db)
stats = process_grades(students)
report = format_report(stats, "成绩报告")
print(report)
```

**2. 需要添加的注解**

| 函数/变量 | 需要的注解 |
|-----------|-----------|
| `calculate_average` | 参数 `List[float]`，返回值 `Optional[float]` |
| `get_student_info` | 参数 `str` 和 `Dict[str, Dict[str, Union[str, int]]]`，返回值 `Optional[Dict[str, Union[str, int]]]` |
| `process_grades` | 参数 `List[Dict[str, Union[str, int]]]`，返回值 `Dict[str, Union[float, int]]` |
| `format_report` | 参数 `Optional[Dict[str, Union[float, int]]]` 和 `str`，返回值 `str` |
| `students` | `List[Dict[str, Union[str, int]]]` |
| `scores` | `List[int]` |
| `student_db` | `Dict[str, Dict[str, Union[str, int]]]` |

**3. 安装并运行 Mypy 检查**

