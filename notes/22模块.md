# Python3 模块笔记

## 一、模块概述

**模块（Module）** 是一个包含 Python 定义和语句的文件，文件名就是模块名加上 `.py` 后缀。

### 模块的作用

| 作用 | 说明 |
|------|------|
| **代码复用** | 将常用功能封装到模块中，可在多个程序中重复使用 |
| **命名空间管理** | 避免命名冲突，不同模块中的同名函数或变量不会互相干扰 |
| **代码组织** | 将代码按功能划分到不同模块中，使程序结构更清晰 |

### 模块内容

模块可以包含：**函数、类、变量以及可执行的代码**。


## 二、import 语句

### 基本语法

```python
import module1[, module2[, ... moduleN]]
```

当解释器遇到 `import` 语句时，如果模块在当前的**搜索路径**中，就会被导入。

### 示例

```python
# 导入 sys 模块
import sys

print('命令行参数如下:')
for i in sys.argv:
    print(i)
print('\nPython 路径为：', sys.path)
```

- `import sys` 引入 Python 标准库中的 `sys.py` 模块
- `sys.argv` 是包含命令行参数的列表
- `sys.path` 包含 Python 解释器自动查找模块的路径列表

### 重要特性

**一个模块只会被导入一次**，无论执行多少次 `import` 语句。这样可以防止模块被重复执行。

### 访问模块内容

导入后，使用 **`模块名.函数名`** 的方式访问：

```python
import fibo

fibo.fib(1000)      # 调用模块中的 fib 函数
fibo.fib2(100)      # 调用模块中的 fib2 函数
print(fibo.__name__)  # 输出: 'fibo'
```



如果打算频繁使用某个函数，可以将其赋值给一个本地名称：

```python
fib = fibo.fib
fib(500)
```




## 三、from … import 语句

### 导入指定部分

从模块中导入一个指定的部分到当前命名空间：

```python
from modname import name1[, name2[, ... nameN]]
```



### 示例

```python
from fibo import fib, fib2

fib(500)   # 直接使用函数名，无需模块前缀
```



> 这种方式**不会**把整个模块导入当前命名空间，只会导入指定的函数。


## 四、from … import * 语句

把一个模块的**所有内容**全部导入到当前命名空间：

```python
from modname import *
```



> ⚠️ **不推荐使用**，容易引起命名冲突。


## 五、给模块起别名（as）

使用 `as` 关键字为模块或函数起别名：

```python
import numpy as np                    # 模块别名
from math import sqrt as square_root  # 函数别名
```




## 六、模块的搜索路径

当导入一个模块时，Python 会按以下顺序查找：

| 优先级 | 搜索位置 |
|--------|----------|
| 1 | **当前目录** |
| 2 | 环境变量 `PYTHONPATH` 指定的目录 |
| 3 | Python 标准库目录 |
| 4 | `.pth` 文件中指定的目录 |

搜索路径存储在 `sys.path` 中，是一个列表。

```python
import sys
print(sys.path)
# 第一项是空串 ''，代表当前目录
```



可以在脚本中**修改 `sys.path`** 来引入不在搜索路径中的模块。


## 七、__name__ 属性

每个模块都有一个 `__name__` 属性：

| 运行方式 | `__name__` 的值 |
|----------|-----------------|
| 模块被**直接运行** | `'__main__'` |
| 模块被**导入** | 模块名（如 `'fibo'`） |



### 应用场景

利用 `__name__` 属性，可以让模块中的某些代码**仅在模块自身运行时执行**，被导入时不执行：

```python
# Filename: using_name.py
if __name__ == '__main__':
    print('程序自身在运行')
else:
    print('我来自另一模块')
```



运行效果：
```bash
$ python using_name.py
程序自身在运行

$ python
>>> import using_name
我来自另一模块
```




## 八、dir() 函数

内置函数 `dir()` 可以**找到模块内定义的所有名称**，以字符串列表的形式返回：

```python
import fibo, sys

dir(fibo)   # ['__name__', 'fib', 'fib2']
dir(sys)    # 包含 sys 模块中的所有名称
```



如果没有给定参数，`dir()` 会**罗列出当前定义的所有名称**：

```python
>>> a = [1, 2, 3, 4, 5]
>>> import fibo
>>> fib = fibo.fib
>>> dir()
['__builtins__', '__name__', 'a', 'fib', 'fibo', 'sys']
```




## 九、标准模块

Python 自带一些标准模块库：

| 模块 | 功能 |
|------|------|
| `math` | 数学运算（平方根、三角函数等） |
| `os` | 操作系统相关功能（文件、目录操作） |
| `sys` | 系统相关的参数和函数 |
| `random` | 生成随机数 |
| `datetime` | 处理日期和时间 |
| `json` | 处理 JSON 数据 |
| `re` | 正则表达式操作 |
| `collections` | 额外数据结构（defaultdict、deque） |
| `itertools` | 迭代器工具 |
| `functools` | 高阶函数工具（reduce、lru_cache） |

有些模块（如 `sys`）是**内置在解释器中的**，可以高效使用，甚至是系统级调用。


## 十、包（Package）

**包**是一种管理 Python 模块命名空间的方式，采用 **"点模块名称"** 的形式。

### 包的结构示例

```
sound/                          # 顶层包
    __init__.py                 # 初始化 sound 包
    formats/                    # 文件格式转换子包
        __init__.py
        wavread.py
        wavwrite.py
        aiffread.py
        ...
    effects/                    # 声音效果子包
        __init__.py
        echo.py
        surround.py
        reverse.py
        ...
    filters/                    # filters 子包
        __init__.py
        equalizer.py
        vocoder.py
        ...
```



### __init__.py 的作用

目录只有包含一个叫做 `__init__.py` 的文件才会被认作是一个包。

- 可以是一个**空文件**
- 也可以包含**初始化代码**
- 还可以为 `__all__` 变量赋值

### 导入包的几种方式

**方式一：导入子模块（需使用全名访问）**

```python
import sound.effects.echo
sound.effects.echo.echofilter(input, output, delay=0.7, atten=4)
```



**方式二：从包中导入子模块（无需冗长前缀）**

```python
from sound.effects import echo
echo.echofilter(input, output, delay=0.7, atten=4)
```



**方式三：直接导入函数或变量**

```python
from sound.effects.echo import echofilter
echofilter(input, output, delay=0.7, atten=4)
```



### __all__ 变量

在包的 `__init__.py` 中定义 `__all__` 列表，可以控制 `from package import *` 时导入的内容：

```python
# 在 sound/effects/__init__.py 中
__all__ = ["echo", "surround", "reverse"]
```

这表示使用 `from sound.effects import *` 时，只会导入这三个子模块。

> 通常**不推荐使用 `import *`**，会导致代码可读性降低。推荐使用 `from Package import specific_submodule`。


## 十一、重点总结

| 知识点 | 要点 |
|--------|------|
| **模块** | `.py` 文件，包含函数、类、变量和可执行代码 |
| **import** | 导入整个模块，使用 `模块名.名称` 访问 |
| **from...import** | 导入指定部分，直接使用名称访问 |
| __from...import *__ | 导入所有内容，**不推荐** |
| **as 别名** | 为模块或函数起别名 |
| **搜索路径** | 当前目录 → PYTHONPATH → 标准库 → .pth 文件 |
| **__name__** | 直接运行时为 `'__main__'`，被导入时为模块名 |
| **dir()** | 列出模块或当前命名空间中的所有名称 |
| **包** | 包含 `__init__.py` 的目录，用点号组织模块 |
| **__all__** | 控制 `from package import *` 的导入列表 |
