# Python3 错误和异常 笔记

## 一、错误与异常概述

### 1.1 两种错误类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **语法错误**（Syntax Error） | 代码不符合 Python 语法规则，解析器无法理解 | `while True print('Hello')` 缺少冒号 `:` |
| **异常**（Exception） | 语法正确，但运行时报错 | 除零、变量未定义、类型不匹配等 |

### 1.2 常见异常示例

```python
# 除零异常
>>> 10 * (1/0)
ZeroDivisionError: division by zero

# 变量未定义
>>> 4 + spam*3
NameError: name 'spam' is not defined

# 类型不匹配
>>> '2' + 2
TypeError: can only concatenate str (not "int") to str
```


异常类型（如 `ZeroDivisionError`、`NameError`、`TypeError`）会作为错误信息的一部分打印出来。


## 二、异常处理 — try/except

### 2.1 基本语法

```python
try:
    # 可能引发异常的代码
except 异常类型:
    # 处理异常的代码
```

### 2.2 执行流程

| 情况 | 执行结果 |
|------|----------|
| try 子句**没有异常** | 跳过 except 子句，try 执行完毕 |
| try 子句**发生异常**且类型匹配 | 忽略 try 剩余部分，执行对应的 except |
| try 子句**发生异常**且类型不匹配 | 异常向上层 try 传递 |

### 2.3 示例：处理用户输入

```python
while True:
    try:
        x = int(input("请输入一个数字: "))
        break
    except ValueError:
        print("您输入的不是数字，请再次尝试输入！")
```


### 2.4 多个 except 子句

一个 `try` 可以有多个 `except`，分别处理不同类型的异常，**最多只有一个分支会被执行**。

```python
try:
    f = open('myfile.txt')
    s = f.readline()
    i = int(s.strip())
except OSError as err:
    print("OS error: {0}".format(err))
except ValueError:
    print("Could not convert data to an integer.")
except:
    print("Unexpected error:", sys.exc_info()[0])
    raise
```


### 2.5 同时处理多个异常

多个异常可以放在一个元组中：

```python
except (RuntimeError, TypeError, NameError):
    pass
```


### 2.6 通配符 except

最后一个 `except` 可以忽略异常名称，作为通配符使用。

> ⚠️ **注意**：通配符会捕获所有异常，应谨慎使用，通常放在最后。


## 三、try/except...else

`else` 子句必须放在所有 `except` 子句之后，**仅在 try 子句没有发生任何异常时执行**。

### 示例：文件读取

```python
for arg in sys.argv[1:]:
    try:
        f = open(arg, 'r')
    except IOError:
        print('cannot open', arg)
    else:
        print(arg, 'has', len(f.readlines()), 'lines')
        f.close()
```


> **最佳实践**：将可能引发异常的代码放在 `try` 中，将正常执行的代码放在 `else` 中，可以避免 `except` 意外捕获 `else` 中的异常。


## 四、try-finally 清理行为

`finally` 子句**无论是否发生异常都会执行**。

### 示例

```python
try:
    runoob()
except AssertionError as error:
    print(error)
else:
    try:
        with open('file.log') as file:
            read_data = file.read()
    except FileNotFoundError as fnf_error:
        print(fnf_error)
finally:
    print('这句话，无论异常是否发生都会执行。')
```


### finally 与异常传播

如果 `try` 中的异常没有被任何 `except` 捕获，该异常会在 `finally` 执行完毕后被重新抛出。

### 复杂示例

```python
def divide(x, y):
    try:
        result = x / y
    except ZeroDivisionError:
        print("division by zero!")
    else:
        print("result is", result)
    finally:
        print("executing finally clause")
```



## 五、抛出异常 — raise

使用 `raise` 语句**主动抛出**一个指定的异常。

### 5.1 基本语法

```python
raise [Exception [, args [, traceback]]]
```


### 5.2 示例

```python
x = 10
if x > 5:
    raise Exception('x 不能大于 5。x 的值为: {}'.format(x))
```


执行结果：
```
Traceback (most recent call last):
  File "test.py", line 3, in <module>
    raise Exception('x 不能大于 5。x 的值为: {}'.format(x))
Exception: x 不能大于 5。x 的值为: 10
```


### 5.3 重新抛出异常

如果只想捕获异常但不处理，可以用简单的 `raise` 再次抛出：

```python
try:
    raise NameError('HiThere')
except NameError:
    print('An exception flew by!')
    raise
```



## 六、用户自定义异常

### 6.1 创建自定义异常

通过继承 `Exception` 类创建自定义异常：

```python
class MyError(Exception):
    def __init__(self, value):
        self.value = value
    def __str__(self):
        return repr(self.value)
```


### 6.2 使用自定义异常

```python
try:
    raise MyError(2*2)
except MyError as e:
    print('My exception occurred, value:', e.value)
```


### 6.3 模块级异常层次结构

为模块建立基础异常类，再派生子类：

```python
class Error(Exception):
    """Base class for exceptions in this module."""
    pass

class InputError(Error):
    """Exception raised for errors in the input."""
    def __init__(self, expression, message):
        self.expression = expression
        self.message = message

class TransitionError(Error):
    """Raised when an operation attempts a state transition that's not allowed."""
    def __init__(self, previous, next, message):
        self.previous = previous
        self.next = next
        self.message = message
```


> **命名惯例**：大多数异常名以 `"Error"` 结尾。


## 七、预定义的清理行为 — with 语句

某些对象（如文件）定义了标准的清理行为。使用 `with` 语句可以**确保对象在使用完后正确清理**，即使发生异常。

### 不推荐的做法（文件未关闭）

```python
for line in open("myfile.txt"):
    print(line, end="")
```


### 推荐做法（使用 with）

```python
with open("myfile.txt") as f:
    for line in f:
        print(line, end="")
```


> 即使处理过程中出现异常，文件 `f` 也**总是会被关闭**。


## 八、重点总结

| 知识点 | 要点 |
|--------|------|
| **语法错误** | 代码不符合语法规则，解析器报错 |
| **异常** | 语法正确但运行时报错 |
| **try/except** | 捕获并处理异常 |
| **多个 except** | 按顺序匹配，最多执行一个 |
| **except 元组** | 一个子句处理多个异常类型 |
| **else** | try 无异常时执行 |
| **finally** | 无论是否异常都执行（清理操作） |
| **raise** | 主动抛出异常 |
| **自定义异常** | 继承 Exception 类 |
| **with 语句** | 自动清理资源（文件等） |

**4. 文件日志（with 语句）**

- 使用 `with open('calc.log', 'a')` 以追加模式打开日志文件
