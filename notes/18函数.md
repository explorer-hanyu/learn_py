# Python3 函数
## 一、函数概述

函数是**组织好的、可重复使用的代码段**，用来实现单一或相关联的功能。

### 函数的作用

| 作用 | 说明 |
|------|------|
| **提高模块性** | 将复杂程序分解为独立的功能模块 |
| **提高代码复用** | 避免重复编写相同逻辑的代码 |
| **便于维护** | 修改功能只需修改函数内部，不影响调用方 |

Python 提供了许多**内建函数**（如 `print()`），你也可以自己创建**用户自定义函数**。


## 二、定义与调用函数

### 2.1 定义函数的规则

使用 `def` 关键字定义函数，规则如下：

| 规则 | 说明 |
|------|------|
| 以 `def` 开头，后接函数名和圆括号 `()` | `def 函数名():` |
| 参数放在圆括号内 | `def 函数名(参数1, 参数2):` |
| 第一行可用**文档字符串**（docstring）说明函数功能 | 可选，用三引号包围 |
| 函数体以冒号 `:` 起始，并**缩进** | 缩进级别必须一致 |
| 用 `return` 返回值，不带表达式的 `return` 返回 `None` | 可选 |

### 2.2 基本语法

```python
def 函数名(参数列表):
    """函数文档字符串（可选）"""
    函数体
    return [表达式]
```



### 2.3 实例

**无参数函数：**
```python
def hello():
    print("Hello World!")

hello()  # 调用函数
```


**带参数的函数（比较两个数，返回较大值）：**
```python
def max(a, b):
    if a > b:
        return a
    else:
        return b

print(max(4, 5))  # 输出: 5
```


**带多个函数和返回值的示例：**
```python
def area(width, height):
    return width * height

def print_welcome(name):
    print("Welcome", name)

print_welcome("Runoob")
w, h = 4, 5
print("area =", area(w, h))
```

输出：
```
Welcome Runoob
area = 20
```

### 2.4 函数调用

定义函数后，可以通过**另一个函数调用**或**直接从命令提示符执行**来调用它。

```python
def printme(str):
    print(str)
    return

printme("我要调用用户自定义函数!")
printme("再次调用同一函数")
```

输出：
```
我要调用用户自定义函数!
再次调用同一函数
```


## 三、参数传递

### 3.1 Python 的变量本质

在 Python 中，**类型属于对象，变量没有类型**。

```python
a = [1, 2, 3]   # a 指向 List 类型对象
a = "Runoob"    # a 指向 String 类型对象
```
变量 `a` 只是一个**对象的引用（指针）**，可以指向不同类型的对象。

### 3.2 不可变对象 vs 可变对象

| 类型 | 说明 | 示例 |
|------|------|------|
| **不可变对象** | 修改时生成新对象，原对象不变 | `int`、`string`、`tuple` |
| **可变对象** | 修改时对象本身内容改变，引用不变 | `list`、`dict` |

**不可变对象示例：**
```python
a = 5    # 创建 int 对象 5，a 指向它
a = 10   # 创建新 int 对象 10，a 指向新对象，5 被丢弃
```


**可变对象示例：**
```python
la = [1, 2, 3, 4]
la[2] = 5   # 修改列表的第三个元素，la 本身指向的对象不变
```


### 3.3 函数参数传递的两种方式

| 传递方式 | 适用类型 | 效果 |
|----------|----------|------|
| **传不可变对象** | `int`、`string`、`tuple` | 函数内修改形参不影响外部实参（类似值传递） |
| **传可变对象** | `list`、`dict` | 函数内修改形参会影响外部实参（类似引用传递） |

> **核心理解**：Python 中一切皆对象，严格来说应理解为**传不可变对象**和**传可变对象**，而非值传递或引用传递。

**传不可变对象实例（通过 `id()` 查看内存地址）：**
```python
def change(a):
    print(id(a))   # 指向的是同一个对象
    a = 10
    print(id(a))   # 新生成一个对象

a = 1
print(id(a))       # 4379369136
change(a)          # 4379369136 → 4379369424
```


**传可变对象实例：**
```python
def changeme(mylist):
    """修改传入的列表"""
    mylist.append([1, 2, 3, 4])
    print("函数内取值:", mylist)

mylist = [10, 20, 30]
changeme(mylist)
print("函数外取值:", mylist)
```

输出：
```
函数内取值: [10, 20, 30, [1, 2, 3, 4]]
函数外取值: [10, 20, 30, [1, 2, 3, 4]]
```



## 四、参数类型

Python 函数支持四种参数类型：

| 参数类型 | 说明 |
|----------|------|
| 必需参数（位置参数） | 按正确顺序传入，数量必须与声明一致 |
| 关键字参数 | 用参数名匹配，顺序可与声明不一致 |
| 默认参数 | 调用时未传入则使用默认值 |
| 不定长参数 | 可接收比声明时更多的参数 |

### 4.1 必需参数（位置参数）

必需参数须以**正确的顺序**传入，**数量必须和声明时一致**。

```python
def printme(str):
    print(str)

printme()   # 报错：缺少参数
```

错误信息：
```
TypeError: printme() missing 1 required positional argument: 'str'
```

### 4.2 关键字参数

使用关键字参数允许**参数顺序与声明时不一致**，Python 解释器能通过参数名匹配。

```python
def printinfo(name, age):
    print("名字:", name)
    print("年龄:", age)

# 顺序与声明不一致，但通过参数名匹配
printinfo(age=50, name="runoob")
```

输出：
```
名字: runoob
年龄: 50
```

### 4.3 默认参数

调用函数时**未传入该参数，则使用默认值**。

```python
def printinfo(name, age=35):
    print("名字:", name)
    print("年龄:", age)

printinfo(age=50, name="runoob")   # age 使用传入值 50
printinfo(name="runoob")           # age 使用默认值 35
```

输出：
```
名字: runoob
年龄: 50
------------------------
名字: runoob
年龄: 35
```

### 4.4 不定长参数

#### 单星号 `*` —— 以**元组**形式接收

`*var_args_tuple` 会以**元组**形式接收所有未命名的变量参数。

```python
def printinfo(arg1, *vartuple):
    print("输出:")
    print(arg1)
    print(vartuple)

printinfo(70, 60, 50)   # 输出: 70 (60, 50)
printinfo(10)           # 输出: 10 ()
```


遍历元组中的参数：
```python
def printinfo(arg1, *vartuple):
    print("输出:")
    print(arg1)
    for var in vartuple:
        print(var)

printinfo(70, 60, 50)
```

输出：
```
输出:
70
60
50
```

#### 双星号 `**` —— 以**字典**形式接收

`**var_args_dict` 会以**字典**形式接收所有未命名的关键字参数。

```python
def printinfo(arg1, **vardict):
    print("输出:")
    print(arg1)
    print(vardict)

printinfo(1, a=2, b=3)   # 输出: 1 {'a': 2, 'b': 3}
```


#### 单独出现的星号 `*`

星号 `*` 单独出现时，`*` 后的参数**必须用关键字传入**。

```python
def f(a, b, *, c):
    return a + b + c

f(1, 2, c=3)   # 正确，返回 6
f(1, 2, 3)     # 报错：c 必须用关键字传入
```



## 五、匿名函数（lambda）

### 5.1 lambda 的特点

Python 使用 `lambda` 创建**匿名函数**（不使用 `def` 定义）。

| 特点 | 说明 |
|------|------|
| 只是一个**表达式**，函数体比 `def` 简单很多 |  |
| 主体是**单个表达式**，不是代码块 |  |
| 拥有自己的命名空间，不能访问自己参数列表之外的变量 |  |
| 不等于 C/C++ 的内联函数 |  |

### 5.2 基本语法

```python
lambda [arg1 [, arg2, ..... argn]]: expression
```


### 5.3 实例

**单参数：**
```python
x = lambda a: a + 10
print(x(5))   # 输出: 15
```


**多参数：**
```python
sum = lambda arg1, arg2: arg1 + arg2
print(sum(10, 20))   # 输出: 30
print(sum(20, 20))   # 输出: 40
```


**在函数内封装 lambda（创建多个匿名函数）：**
```python
def myfunc(n):
    return lambda a: a * n

mydoubler = myfunc(2)   # 创建乘以 2 的函数
mytripler = myfunc(3)   # 创建乘以 3 的函数

print(mydoubler(11))    # 输出: 22
print(mytripler(11))    # 输出: 33
```



## 六、return 语句

`return [表达式]` 用于**退出函数**，并选择性地返回一个值。

| 情况 | 返回值 |
|------|--------|
| `return 表达式` | 返回表达式的值 |
| `return` 或不写 `return` | 返回 `None` |



```python
def sum(arg1, arg2):
    total = arg1 + arg2
    print("函数内:", total)
    return total

total = sum(10, 20)
print("函数外:", total)
```

输出：
```
函数内: 30
函数外: 30
```


## 七、强制位置参数（Python 3.8+）

Python 3.8 新增了 `/` 语法，用于**指明函数形参必须使用指定位置参数，不能使用关键字参数**。

```python
def f(a, b, /, c, d, *, e, f):
    print(a, b, c, d, e, f)
```

| 参数位置 | 要求 |
|----------|------|
| `/` 左侧（a, b） | 必须使用位置参数 |
| `/` 与 `*` 之间（c, d） | 位置参数或关键字参数均可 |
| `*` 右侧（e, f） | 必须使用关键字参数 |



```python
# 正确
f(10, 20, 30, d=40, e=50, f=60)

# 错误：b 不能使用关键字参数
f(10, b=20, c=30, d=40, e=50, f=60)

# 错误：e 必须使用关键字参数
f(10, 20, 30, 40, 50, f=60)
```


## 八、重点总结

| 知识点 | 要点 |
|--------|------|
| **定义函数** | `def 函数名(参数):` + 缩进函数体 |
| **文档字符串** | 函数第一行用三引号 `"""..."""` 说明功能 |
| **返回值** | `return` 返回值，不带 `return` 返回 `None` |
| **参数传递** | 不可变对象（值传递）vs 可变对象（引用传递） |
| **必需参数** | 按顺序传入，数量必须匹配 |
| **关键字参数** | 用参数名匹配，顺序可调 |
| **默认参数** | 调用时未传入则使用默认值 |
| **不定长参数** | `*args`（元组）和 `**kwargs`（字典） |
| **匿名函数** | `lambda 参数: 表达式`，单行表达式 |
| **强制位置参数** | `/` 左侧参数必须用位置传递（Python 3.8+） |
