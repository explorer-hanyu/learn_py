# Python3 多线程笔记

## 一、多线程概述

多线程类似于**同时执行多个不同程序**，线程在执行过程中与进程有区别。每个独立的线程有一个程序运行的入口、顺序执行序列和程序的出口。

### 多线程的优点

- 可以把占据长时间的程序中的任务放到后台去处理
- 用户界面可以更加吸引人（如弹出进度条）
- 程序的运行速度可能加快
- 在等待任务（用户输入、文件读写、网络收发数据等）时释放资源

### 线程的分类

| 类型 | 说明 |
|------|------|
| 内核线程 | 由操作系统内核创建和撤销 |
| 用户线程 | 不需要内核支持而在用户程序中实现的线程 |


## 二、Python3 线程模块

Python3 线程中常用的两个模块：

| 模块 | 说明 |
|------|------|
| `_thread` | 低级别的、原始的线程以及一个简单的锁，功能有限 |
| `threading` | **推荐使用**，包含 `_thread` 的所有方法，功能更丰富 |

> Python3 中不能再使用 `"thread"` 模块，为了兼容性，`thread` 被重命名为 `_thread`。


## 三、使用 _thread 模块

调用 `_thread` 模块中的 `start_new_thread()` 函数来产生新线程：

```python
_thread.start_new_thread(function, args[, kwargs])
```

| 参数 | 说明 |
|------|------|
| `function` | 线程函数 |
| `args` | 传递给线程函数的参数，**必须是个 tuple 类型** |
| `kwargs` | 可选参数 |

### 示例

```python
#!/usr/bin/python3
import _thread
import time

def print_time(threadName, delay):
    count = 0
    while count < 5:
        time.sleep(delay)
        count += 1
        print("%s: %s" % (threadName, time.ctime(time.time())))

try:
    _thread.start_new_thread(print_time, ("Thread-1", 2, ))
    _thread.start_new_thread(print_time, ("Thread-2", 4, ))
except:
    print("Error: 无法启动线程")

while 1:
    pass
```


## 四、threading 模块常用方法

| 方法 | 说明 |
|------|------|
| `threading.current_thread()` | 返回当前的线程变量 |
| `threading.enumerate()` | 返回包含正在运行的线程的列表（不包括启动前和终止后的线程） |
| `threading.active_count()` | 返回正在运行的线程数量，与 `len(threading.enumerate())` 结果相同 |
| `threading.Thread(target, args=(), kwargs={}, daemon=None)` | 创建 Thread 类的实例 |

### Thread 类的方法与属性

| 方法/属性 | 说明 |
|-----------|------|
| `__init__(group, target, name, args, kwargs, daemon)` | 初始化 Thread 对象 |
| `start()` | 启动线程，将调用 `run()` 方法 |
| `run()` | 线程在此方法中定义要执行的代码 |
| `join(timeout=None)` | 等待线程终止，阻塞直到被调用线程终止 |
| `is_alive()` | 返回线程是否在运行 |
| `getName()` / `setName(name)` | 获取/设置线程名称 |
| `ident` | 线程的唯一标识符 |
| `daemon` | 线程的守护标志 |


## 五、创建线程的两种方式

### 方式一：函数式（推荐用于简单任务）

```python
import threading
import time

def print_numbers():
    for i in range(5):
        time.sleep(1)
        print(i)

thread = threading.Thread(target=print_numbers)
thread.start()
thread.join()
```

### 方式二：继承 Thread 类（推荐用于复杂任务）

通过继承 `threading.Thread` 类，重写 `run()` 方法：

```python
import threading
import time

exitFlag = 0

class myThread(threading.Thread):
    def __init__(self, threadID, name, delay):
        threading.Thread.__init__(self)
        self.threadID = threadID
        self.name = name
        self.delay = delay

    def run(self):
        print("开始线程：" + self.name)
        print_time(self.name, self.delay, 5)
        print("退出线程：" + self.name)

def print_time(threadName, delay, counter):
    while counter:
        if exitFlag:
            threadName.exit()
        time.sleep(delay)
        print("%s: %s" % (threadName, time.ctime(time.time())))
        counter -= 1

thread1 = myThread(1, "Thread-1", 1)
thread2 = myThread(2, "Thread-2", 2)

thread1.start()
thread2.start()
thread1.join()
thread2.join()
print("退出主线程")
```


## 六、线程同步（Lock / RLock）

### 为什么需要同步

当多个线程共同对某个数据修改时，可能出现不可预料的结果。为了保证数据的正确性，需要对多个线程进行同步。

### 锁的两种状态

锁有 **锁定** 和 **未锁定** 两种状态。线程访问共享数据时，必须先获得锁定；如果已有其他线程获得锁定，则该线程**暂停（同步阻塞）**，等到锁释放后再继续。

### Lock 与 RLock

使用 Thread 对象的 `Lock` 和 `RLock` 可以实现简单的线程同步，它们都有 `acquire` 方法和 `release` 方法。

| 锁类型 | 特点 |
|--------|------|
| `Lock` | 普通锁，不可重入 |
| `RLock` | 可重入锁，同一个线程可以多次请求同一把锁 |

### 示例

```python
#!/usr/bin/python3
import threading
import time

class myThread(threading.Thread):
    def __init__(self, threadID, name, delay):
        threading.Thread.__init__(self)
        self.threadID = threadID
        self.name = name
        self.delay = delay

    def run(self):
        print("开启线程： " + self.name)
        # 获取锁，用于线程同步
        threadLock.acquire()
        print_time(self.name, self.delay, 3)
        # 释放锁，开启下一个线程
        threadLock.release()

def print_time(threadName, delay, counter):
    while counter:
        time.sleep(delay)
        print("%s: %s" % (threadName, time.ctime(time.time())))
        counter -= 1

threadLock = threading.Lock()
threads = []

thread1 = myThread(1, "Thread-1", 1)
thread2 = myThread(2, "Thread-2", 2)

thread1.start()
thread2.start()

threads.append(thread1)
threads.append(thread2)

for t in threads:
    t.join()
print("退出主线程")
```


## 七、线程优先级队列（Queue）

### Queue 模块

Python 的 `Queue` 模块提供了**同步的、线程安全的**队列类，包括：

| 队列类型 | 说明 |
|----------|------|
| `Queue` | FIFO（先入先出）队列 |
| `LifoQueue` | LIFO（后入先出）队列 |
| `PriorityQueue` | 优先级队列 |

这些队列都实现了锁原语，能够在多线程中直接使用，实现线程间的同步。

### Queue 常用方法

| 方法 | 说明 |
|------|------|
| `qsize()` | 返回队列的大小 |
| `empty()` | 队列为空返回 True |
| `full()` | 队列满了返回 True |
| `get([block[, timeout]])` | 获取队列，timeout 等待时间 |
| `get_nowait()` | 相当 `Queue.get(False)` |
| `put(item)` | 写入队列 |
| `put_nowait(item)` | 相当 `Queue.put(item, False)` |
| `task_done()` | 向任务已完成的队列发送一个信号 |
| `join()` | 等到队列为空，再执行别的操作 |

- 使用锁保证打印不会出现交错

```python
#!/usr/bin/python3
import threading
import queue
import time

# ========== 全局变量 ==========
task_queue = queue.______()          # 填空：创建 FIFO 队列
log_lock = threading.______()        # 填空：创建锁
exit_flag = False

# ========== 下载线程类 ==========
class DownloadThread(threading.Thread):
    def __init__(self, thread_id, name, q, lock):
        threading.Thread.______(self)  # 填空：调用父类构造方法
        self.thread_id = thread_id
        self.name = name
        self.q = q
        self.lock = lock

    def run(self):
        with self.lock:
            print(f"开启线程：{self.name}")
        while not exit_flag:
            try:
                # 从队列获取任务，超时 1 秒
                filename = self.q.______(timeout=1)  # 填空：get
                download_file(self.name, filename, self.lock)
                self.q.______()  # 填空：task_done
            except queue.______:  # 填空：Empty
                continue
        with self.lock:
            print(f"退出线程：{self.name}")

# ========== 下载处理函数 ==========
def download_file(thread_name, filename, lock):
    with lock:
        print(f"[{thread_name}] 开始下载: {filename}")
    time.sleep(1)  # 模拟下载耗时
    with lock:
        print(f"[{thread_name}] 下载完成: {filename}")

# ========== 主程序 ==========
if __name__ == "__main__":
    # 待下载文件列表
    files = ["file1.zip", "file2.mp4", "file3.pdf",
             "file4.jpg", "file5.doc", "file6.mp3"]

    # 填充队列
    for f in files:
        task_queue.______(f)  # 填空：put

    # 创建并启动下载线程
    threads = []
    for i in range(1, 4):
        thread = DownloadThread(i, f"Downloader-{i}", task_queue, log_lock)
        thread.______()  # 填空：start
        threads.______(thread)  # 填空：append

    # 等待所有线程完成
    for t in threads:
        t.______()  # 填空：join

    # 通知线程退出
    exit_flag = True

    # 等待队列清空
    task_queue.______()  # 填空：join

    print("\n所有下载任务完成")
```
