# Python3 OS 文件/目录方法笔记
## 一、os 模块概述

`os` 模块是 Python 标准库中**与操作系统交互**的核心模块。通过 `os` 模块，你可以执行文件操作、目录操作、环境变量管理、进程管理等任务。

### 特点

- **跨平台**：Windows、Linux、macOS 上使用相同的代码
- **使用前需导入**：`import os`


## 二、常用功能速查

### 2.1 目录操作

| 方法 | 描述 | 示例 |
|------|------|------|
| `os.getcwd()` | 获取当前工作目录的路径 | `os.getcwd()` → `'/home/user'` |
| `os.chdir(path)` | 改变当前工作目录 | `os.chdir('/tmp')` |
| `os.listdir(path)` | 列出指定目录中的所有文件和子目录 | `os.listdir('.')` → `['file1.txt', 'dir1']` |
| `os.mkdir(path)` | 创建一个新目录（目录已存在则报错） | `os.mkdir('new_folder')` |
| `os.makedirs(path)` | 递归创建多层目录 | `os.makedirs('a/b/c')` |
| `os.rmdir(path)` | 删除**空目录**（非空则报错） | `os.rmdir('empty_folder')` |
| `os.removedirs(path)` | 递归删除目录 | `os.removedirs('a/b/c')` |
| `os.rename(src, dst)` | 重命名文件或目录 | `os.rename('old.txt', 'new.txt')` |
| `os.renames(src, dst)` | 递归重命名（自动创建中间目录） | `os.renames('a/b/old.txt', 'c/d/new.txt')` |

### 2.2 文件操作

| 方法 | 描述 | 示例 |
|------|------|------|
| `os.remove(path)` | 删除文件（文件不存在则报错） | `os.remove('file.txt')` |
| `os.rename(src, dst)` | 重命名文件或目录 | `os.rename('old.txt', 'new.txt')` |
| `os.stat(path)` | 获取文件或目录的状态信息 | `os.stat('file.txt')` |

### 2.3 环境变量与系统命令

| 方法 | 描述 | 示例 |
|------|------|------|
| `os.getenv(key)` | 获取指定环境变量的值（不存在返回 None） | `os.getenv('HOME')` |
| `os.system(command)` | 在 shell 中执行系统命令 | `os.system('ls -l')` |

### 2.4 路径操作（os.path 子模块）

| 方法 | 描述 | 示例 |
|------|------|------|
| `os.path.join(a, b)` | 拼接路径 | `os.path.join('dir', 'file.txt')` |
| `os.path.exists(path)` | 判断路径是否存在 | `os.path.exists('file.txt')` |
| `os.path.isfile(path)` | 判断是否为文件 | `os.path.isfile('file.txt')` |
| `os.path.isdir(path)` | 判断是否为目录 | `os.path.isdir('folder')` |
| `os.path.abspath(path)` | 返回绝对路径 | `os.path.abspath('file.txt')` |
| `os.path.basename(path)` | 返回路径中的文件名 | `os.path.basename('/a/b/c.txt')` → `'c.txt'` |
| `os.path.dirname(path)` | 返回路径中的目录部分 | `os.path.dirname('/a/b/c.txt')` → `'/a/b'` |
| `os.path.splitext(path)` | 分离文件名和扩展名 | `os.path.splitext('file.txt')` → `('file', '.txt')` |
| `os.path.getsize(path)` | 获取文件大小（字节） | `os.path.getsize('file.txt')` |
| `os.path.getmtime(path)` | 获取文件修改时间 | `os.path.getmtime('file.txt')` |


## 三、常用方法详解

### 3.1 获取和切换工作目录

```python
import os

# 获取当前工作目录
current = os.getcwd()
print(f"当前目录: {current}")

# 切换到指定目录
os.chdir('/tmp')
print(f"切换后: {os.getcwd()}")
```

### 3.2 列出目录内容

```python
import os

# 列出当前目录所有内容
items = os.listdir('.')
for item in items:
    print(item)

# 区分文件和目录
for item in os.listdir('.'):
    full_path = os.path.join('.', item)
    if os.path.isdir(full_path):
        print(f"[目录] {item}")
    else:
        print(f"[文件] {item}")
```

### 3.3 创建和删除目录

```python
import os

# 创建单层目录
os.mkdir('new_folder')

# 递归创建多层目录
os.makedirs('parent/child/grandchild')

# 删除空目录
os.rmdir('empty_folder')

# 递归删除（从内到外删除空目录）
os.removedirs('parent/child/grandchild')
```

> **注意**：`os.rmdir()` 只能删除空目录，非空目录需使用 `shutil.rmtree()`。

### 3.4 文件操作

```python
import os

# 删除文件
os.remove('temp.txt')

# 重命名文件
os.rename('old_name.txt', 'new_name.txt')

# 获取文件信息
stat_info = os.stat('file.txt')
print(f"大小: {stat_info.st_size} 字节")
print(f"修改时间: {stat_info.st_mtime}")
```

### 3.5 环境变量

```python
import os

# 获取环境变量
home = os.getenv('HOME')
path = os.getenv('PATH')
print(f"HOME: {home}")
print(f"PATH: {path}")
```

### 3.6 执行系统命令

```python
import os

# 执行命令，返回退出状态码
status = os.system('ls -la')
print(f"命令退出码: {status}")
```


## 四、重点总结

| 知识点 | 要点 |
|--------|------|
| **导入方式** | `import os` |
| **跨平台** | 同一套代码可在 Windows/Linux/macOS 运行 |
| **目录操作** | `getcwd()`、`chdir()`、`listdir()`、`mkdir()`、`makedirs()`、`rmdir()`、`removedirs()` |
| **文件操作** | `remove()`、`rename()`、`stat()` |
| **路径操作** | 使用 `os.path` 子模块处理路径 |
| **环境变量** | `getenv()` 获取环境变量 |
| **系统命令** | `system()` 执行 shell 命令 |

### 场景描述

你需要开发一个**命令行文件管理器**，支持浏览目录、创建/删除文件夹、创建/删除文件、重命名等基本操作。


### 具体要求

**1. 浏览目录（listdir + 区分文件/目录）**

编写函数 `list_current_dir()`：
- 使用 `os.getcwd()` 获取并打印当前工作目录
- 使用 `os.listdir('.')` 列出当前目录所有内容
- 使用 `os.path.isdir()` 和 `os.path.isfile()` 区分文件和目录，分别用 `[DIR]` 和 `[FILE]` 前缀打印

**2. 切换目录（chdir）**

编写函数 `change_dir(path)`：
- 使用 `os.chdir(path)` 切换到指定目录
- 捕获 `FileNotFoundError` 异常，打印 `"目录不存在"`
- 切换成功后打印新的工作目录

**3. 创建目录（mkdir + makedirs）**

编写函数 `create_dir(path)`：
- 如果路径不包含多层目录，使用 `os.mkdir(path)`
- 如果包含多层目录（如 `a/b/c`），使用 `os.makedirs(path)`
- 捕获 `FileExistsError`，打印 `"目录已存在"`

**4. 删除目录（rmdir + 判断是否为空）**

编写函数 `delete_dir(path)`：
- 先使用 `os.path.isdir()` 判断是否为目录
- 使用 `os.listdir(path)` 检查目录是否为空
- 如果为空，使用 `os.rmdir(path)` 删除
- 如果不为空，打印 `"目录非空，无法删除"`

**5. 删除文件（remove）**

编写函数 `delete_file(path)`：
- 使用 `os.path.isfile()` 判断是否为文件
- 如果是文件，使用 `os.remove(path)` 删除
- 捕获 `FileNotFoundError`，打印 `"文件不存在"`

**6. 重命名（rename）**

编写函数 `rename_item(old, new)`：
- 使用 `os.rename(old, new)` 重命名
- 捕获 `FileNotFoundError`，打印 `"源文件不存在"`

**7. 获取文件信息（stat + os.path）**

编写函数 `file_info(path)`：
- 使用 `os.path.exists()` 判断是否存在
- 使用 `os.path.getsize()` 获取文件大小
- 使用 `os.path.getmtime()` 获取修改时间（需转换为可读格式）
- 使用 `os.path.abspath()` 获取绝对路径
- 打印所有信息

**8. 主菜单**

使用 `while True` 循环显示菜单：
```
===== 文件管理器 =====
1. 浏览当前目录
2. 切换目录
3. 创建目录
4. 删除目录
5. 删除文件
6. 重命名
7. 查看文件信息
8. 退出
请选择（1-8）：
```

根据用户输入调用对应函数。
