# Python3 面向对象

## 一、面向对象技术简介

| 术语 | 说明 |
|------|------|
| **类（Class）** | 用来描述具有相同属性和方法的对象的集合。对象是类的实例 |
| **方法** | 类中定义的函数 |
| **类变量** | 在整个实例化的对象中是公用的，定义在类中且在函数体之外 |
| **实例变量** | 用 `self` 修饰的变量，属于具体实例 |
| **方法重写** | 子类对父类继承来的方法进行改写 |
| **继承** | 派生类继承基类的字段和方法 |
| **实例化** | 创建一个类的具体对象 |
| **对象** | 通过类定义的数据结构实例 |

Python 的类机制提供了面向对象编程的所有基本功能：**支持多继承**，派生类可以覆盖基类中的任何方法。


## 二、类定义

```python
class ClassName:
    <statement-1>
    ...
    <statement-N>
```

类实例化后，可以通过类名访问其属性。


## 三、类对象

类对象支持两种操作：**属性引用**和**实例化**。

```python
class MyClass:
    """一个简单的类实例"""
    i = 12345                # 类变量
    def f(self):
        return 'hello world'

# 实例化类
x = MyClass()

# 访问类的属性和方法
print(x.i)      # 输出: 12345
print(x.f())    # 输出: hello world
```


## 四、构造方法 `__init__()`

`__init__()` 是类的**构造方法**，在类实例化时**自动调用**。

```python
class Complex:
    def __init__(self, realpart, imagpart):
        self.r = realpart
        self.i = imagpart

x = Complex(3.0, -4.5)
print(x.r, x.i)   # 输出: 3.0 -4.5
```


## 五、`self` 参数

- `self` 代表**类的实例**（对象自身），而非类本身
- 类方法的第一个参数必须为 `self`（按惯例命名，**不是关键字**，可用其他名称）
- 通过 `self` 可以在类方法中访问和操作实例的属性

```python
class Test:
    def prt(self):
        print(self)
        print(self.__class__)

t = Test()
t.prt()
# 输出: <__main__.Test object at 0x...>
#       <class '__main__.Test'>
```


## 六、类的方法

类内部使用 `def` 定义方法，**第一个参数必须是 `self`**，代表类的实例。

```python
class People:
    # 类变量
    name = ''
    age = 0
    # 私有属性（双下划线开头）
    __weight = 0

    # 构造方法
    def __init__(self, n, a, w):
        self.name = n
        self.age = a
        self.__weight = w

    def speak(self):
        print("%s 说: 我 %d 岁。" % (self.name, self.age))
```


## 七、继承

### 7.1 单继承

```python
class DerivedClassName(BaseClassName):
    <statement-1>
    ...
    <statement-N>
```

**子类会继承父类的属性和方法**。

```python
class Student(People):          # 继承 People
    grade = ''
    def __init__(self, n, a, w, g):
        People.__init__(self, n, a, w)   # 调用父类构造方法
        self.grade = g

    # 方法重写
    def speak(self):
        print("%s 说: 我 %d 岁了，我在读 %d 年级" % (self.name, self.age, self.grade))
```

### 7.2 多继承

```python
class DerivedClassName(Base1, Base2, Base3):
    <statement-1>
    ...
    <statement-N>
```

**查找顺序**：若父类中有同名方法，Python **从左至右搜索**。

另一个类，多继承之前的准备:
```python
class speaker():
    topic = ''
    name = ''
    def __init__(self,n,t):
        self.name = n
        self.topic = t
    def speak(self):
        print("我叫 %s，我是一个演说家，我演讲的主题是 %s"%(self.name,self.topic))
```

```python
class Sample(Speaker, Student):   # 继承顺序：Speaker 在前
    def __init__(self, n, a, w, g, t):
        Student.__init__(self, n, a, w, g)
        Speaker.__init__(self, n, t)

test = Sample("Tim", 25, 80, 4, "Python")
test.speak()   # 调用的是 Speaker 的 speak 方法（因为排在前面）
```


## 八、方法重写

子类可以重写父类的方法。使用 `super()` 可以调用父类被覆盖的方法。

```python
class Parent:
    def myMethod(self):
        print('调用父类方法')

class Child(Parent):
    def myMethod(self):
        print('调用子类方法')

c = Child()
c.myMethod()                    # 调用子类方法
super(Child, c).myMethod()      # 调用父类方法
```


## 九、类的私有属性与方法

| 语法 | 说明 |
|------|------|
| `__private_attrs` | 双下划线开头，**私有属性**，不能在类外部访问 |
| `__private_method` | 双下划线开头，**私有方法**，只能在类内部调用 |

```python
class JustCounter:
    __secretCount = 0   # 私有变量
    publicCount = 0     # 公开变量

    def count(self):
        self.__secretCount += 1
        self.publicCount += 1

counter = JustCounter()
counter.count()
counter.count()
print(counter.publicCount)        # 输出: 2
print(counter.__secretCount)      # 报错！不能访问私有变量
```

| `__truediv__` | 除法运算 |


## 十一、运算符重载

通过对专有方法进行重载，可以实现运算符重载。

```python
class Vector:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def __str__(self):
        return 'Vector (%d, %d)' % (self.a, self.b)

    def __add__(self, other):
        return Vector(self.a + other.a, self.b + other.b)

v1 = Vector(2, 10)
v2 = Vector(5, -2)
print(v1 + v2)   # 输出: Vector (7, 8)
```
