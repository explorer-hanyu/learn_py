# Python 量化 笔记

## 一、什么是量化

**Python 量化**是指利用 Python 编程语言以及相关的库和工具，来进行**金融市场数据分析、策略开发和交易执行**的过程。

Python 由于其简洁、易学、强大的生态系统和丰富的金融库，成为量化交易的首选编程语言之一。量化交易允许交易者通过**系统性的方法**来制定和执行交易策略，提高交易效率和决策的科学性。

量化主要是通过**数学和统计学的方法**，利用计算机技术对金融市场进行量化分析，从而制定和执行交易策略。


## 二、量化交易流程

量化交易的核心流程包括以下步骤：

| 步骤 | 说明 |
|------|------|
| **策略定义** | 确定何时买入、卖出或持仓的规则，可能涉及技术指标、移动平均线策略、趋势跟踪、套利等 |
| **数据获取** | 获取过去的市场数据，包括股票、期货、外汇等金融工具的价格、成交量等信息 |
| **模拟交易** | 根据定义的策略，模拟在历史数据上执行交易，计算每次交易的收益和损失 |
| **绩效评估** | 计算年化收益率、最大回撤、夏普比率等指标，评估策略表现 |
| **策略优化** | 根据回测结果调整参数或修改规则，重新回测 |
| **未来性检验** | 确保只使用历史数据的一部分来模拟实际交易，防止未来数据泄漏 |

以上步骤参考了量化回测的标准流程。

## 五、移动平均交叉策略

移动平均交叉策略是量化中最经典的入门策略之一，基本思想是**比较短期和长期移动平均线来生成买入和卖出信号**。

- 短期均线（如 50 日均线）**上穿**长期均线（如 200 日均线）→ 买入信号
- 短期均线**下穿**长期均线 → 卖出信号

计算移动平均线：

```python
data['MA_50'] = data['Close'].rolling(window=50).mean()
data['MA_200'] = data['Close'].rolling(window=200).mean()
```

生成信号：

```python
data['Signal'] = 0
data['Signal'][data['MA_50'] > data['MA_200']] = 1    # 买入信号
data['Signal'][data['MA_50'] < data['MA_200']] = -1   # 卖出信号
```


## 六、量化回测

**回测**是在历史市场数据上模拟和评估交易策略的过程，用于评估策略在过去市场行为上的表现。

### 回测中的关键概念

| 概念 | 说明 |
|------|------|
| **未来数据泄漏** | 在设计和评估策略时，不能使用当时尚未发生的数据 |
| **`shift(1)`** | 将信号向后移动一天，确保用**昨天收盘后的信号**来执行今天的交易，避免未来数据偏差 |
| **累计收益** | 使用 `(1 + 每日策略收益).cumprod()` 计算策略的累计收益曲线 |

### 回测核心代码

```python
# 计算每日收益率
data['Daily_Return'] = data['Close'].pct_change()

# 计算策略收益（shift(1) 避免未来数据偏差）
data['Strategy_Return'] = data['Signal'].shift(1) * data['Daily_Return']

# 计算累计收益
data['Cumulative_Return'] = (1 + data['Strategy_Return']).cumprod()
```

- 计算策略累计收益：`(1 + Strategy_Return).cumprod()`

**7. 输出统计信息**

- 打印策略的总收益率（累计收益的最后一个值 - 1）
