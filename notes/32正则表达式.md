# Python3 正则表达式 笔记

## 一、概述

正则表达式是一个特殊的字符序列，用于**检查一个字符串是否与某种模式匹配**。Python 通过 `re` 模块提供正则表达式功能。

### 核心模块
```python
import re
```


## 二、re.match() —— 从起始位置匹配

`re.match()` 尝试**从字符串的起始位置**匹配一个模式。如果不是起始位置匹配成功，返回 `None`。

### 语法
```python
re.match(pattern, string, flags=0)
```

| 参数 | 描述 |
|------|------|
| `pattern` | 匹配的正则表达式 |
| `string` | 要匹配的字符串 |
| `flags` | 标志位，控制匹配方式 |

### 匹配对象方法

| 方法 | 描述 |
|------|------|
| `group(num=0)` | 匹配的整个表达式的字符串，可传入多个组号返回元组 |
| `groups()` | 返回包含所有小组字符串的元组 |

### 示例
```python
import re

# 起始位置匹配成功
print(re.match('www', 'www.runoob.com').span())  # (0, 3)

# 非起始位置匹配失败
print(re.match('com', 'www.runoob.com'))         # None
```

### 使用分组
```python
line = "Cats are smarter than dogs"
matchObj = re.match(r'(.*) are (.*?) .*', line, re.M | re.I)

if matchObj:
    print(matchObj.group())     # Cats are smarter than dogs
    print(matchObj.group(1))    # Cats
    print(matchObj.group(2))    # smarter
```

> **`r'(.*) are (.*?) .*'` 解读**：
> - `.*`：任意匹配除换行符外的任何单个或多个字符（贪婪）
> - `.*?`："非贪婪"模式，只保存第一个匹配到的子串
> - `re.M|re.I`：同时启用多行模式和忽略大小写


## 三、re.search() —— 扫描整个字符串

`re.search()` **扫描整个字符串**并返回**第一个成功的匹配**。

### 语法
```python
re.search(pattern, string, flags=0)
```

### 示例
```python
import re

print(re.search('www', 'www.runoob.com').span())  # (0, 3)
print(re.search('com', 'www.runoob.com').span())  # (11, 14)
```


## 四、re.match() 与 re.search() 的区别

| 函数 | 匹配方式 |
|------|----------|
| `re.match()` | **只匹配字符串开头**，开头不符合则返回 `None` |
| `re.search()` | **匹配整个字符串**，直到找到第一个匹配 |

### 对比示例
```python
line = "Cats are smarter than dogs"

# match 从开头匹配 "dogs" —— 失败
print(re.match(r'dogs', line, re.M | re.I))  # None

# search 在整个字符串中查找 "dogs" —— 成功
print(re.search(r'dogs', line, re.M | re.I).group())  # dogs
```


## 五、re.sub() —— 检索和替换

`re.sub()` 用于替换字符串中的匹配项。

### 语法
```python
re.sub(pattern, repl, string, count=0, flags=0)
```

| 参数 | 描述 |
|------|------|
| `pattern` | 正则模式字符串 |
| `repl` | 替换的字符串，也可为一个函数 |
| `string` | 要被查找替换的原始字符串 |
| `count` | 最大替换次数，默认 0 表示替换所有 |
| `flags` | 匹配模式 |

### 示例：删除注释和提取数字
```python
phone = "2004-959-559 # 这是一个电话号码"

# 删除注释
num = re.sub(r'#.*$', "", phone)
print(num)  # 2004-959-559

# 移除非数字内容
num = re.sub(r'\D', "", phone)
print(num)  # 2004959559
```

### repl 参数为函数
```python
def double(matched):
    value = int(matched.group('value'))
    return str(value * 2)

s = 'A23G4HFD567'
print(re.sub('(?P<value>\d+)', double, s))  # A46G8HFD1134
```


## 六、re.compile() —— 编译正则表达式

`compile()` 将正则表达式编译成一个 **Pattern 对象**，供 `match()` 和 `search()` 使用。

### 语法
```python
re.compile(pattern[, flags])
```

### 示例
```python
import re

pattern = re.compile(r'\d+')  # 匹配至少一个数字

# 从指定位置开始匹配
m = pattern.match('one12twothree34four', 3, 10)  # 从索引3开始
print(m.group())  # '12'
```

### Match 对象方法

| 方法 | 描述 |
|------|------|
| `group([g1, ...])` | 获得匹配的子串 |
| `start([group])` | 匹配子串的起始位置 |
| `end([group])` | 匹配子串的结束位置（索引+1） |
| `span([group])` | 返回 `(start, end)` 元组 |

### 多分组示例
```python
pattern = re.compile(r'([a-z]+) ([a-z]+)', re.I)
m = pattern.match('Hello World Wide Web')

print(m.group(0))   # 'Hello World'
print(m.group(1))   # 'Hello'
print(m.group(2))   # 'World'
print(m.groups())   # ('Hello', 'World')
```


## 七、re.findall() —— 查找所有匹配

`findall()` 返回**所有匹配的子串**列表。`match` 和 `search` 只匹配一次，`findall` 匹配所有。

### 语法
```python
re.findall(pattern, string, flags=0)
# 或
pattern.findall(string[, pos[, endpos]])
```

### 示例：查找所有数字
```python
import re

result = re.findall(r'\d+', 'runoob 123 google 456')
print(result)  # ['123', '456']

pattern = re.compile(r'\d+')
result = pattern.findall('run88oob123google456', 0, 10)
print(result)  # ['88', '12']
```

### 多个匹配模式（返回元组列表）
```python
result = re.findall(r'(\w+)=(\d+)', 'set width=20 and height=10')
print(result)  # [('width', '20'), ('height', '10')]
```


## 八、re.finditer() —— 返回迭代器

与 `findall` 类似，但返回一个**迭代器**。

```python
import re

it = re.finditer(r"\d+", "12a32bc43jf3")
for match in it:
    print(match.group())  # 12 32 43 3
```


## 九、re.split() —— 分割字符串

按匹配的子串将字符串分割后返回列表。

### 语法
```python
re.split(pattern, string[, maxsplit=0, flags=0])
```

### 示例
```python
import re

# 按非字母数字字符分割
print(re.split('\W+', 'runoob, runoob, runoob.'))
# ['runoob', 'runoob', 'runoob', '']

# 保留分隔符
print(re.split('(\W+)', ' runoob, runoob, runoob.'))
# ['', ' ', 'runoob', ', ', 'runoob', ', ', 'runoob', '.', '']

# 限制分割次数
print(re.split('\W+', ' runoob, runoob, runoob.', 1))
# ['', 'runoob, runoob, runoob.']
```


## 十、正则表达式修饰符（可选标志）

| 修饰符 | 描述 |
|--------|------|
| `re.I` / `re.IGNORECASE` | 使匹配对大小写不敏感 |
| `re.M` / `re.MULTILINE` | 多行模式，`^` 和 `$` 匹配每行的开头和结尾 |
| `re.S` / `re.DOTALL` | 使 `.` 匹配包括换行符在内的任意字符 |
| `re.X` / `re.VERBOSE` | 忽略空格和注释，组织复杂正则 |
| `re.L` | 特殊字符集依赖于当前环境 |
| `re.ASCII` | 使 `\w`、`\d`、`\s` 仅匹配 ASCII 字符 |

> 多个标志可通过按位或 `|` 组合使用。


## 十一、正则表达式模式语法速查

### 元字符

| 模式 | 描述 |
|------|------|
| `^` | 匹配字符串的开头 |
| `$` | 匹配字符串的末尾 |
| `.` | 匹配除换行符外的任意字符 |
| `[...]` | 匹配括号内的任意一个字符 |
| `[^...]` | 匹配不在括号内的任意字符 |
| `re*` | 匹配 0 个或多个表达式 |
| `re+` | 匹配 1 个或多个表达式 |
| `re?` | 匹配 0 个或 1 个表达式（非贪婪） |
| `re{n}` | 精确匹配 n 个前面表达式 |
| `re{n,}` | 匹配至少 n 个前面表达式 |
| `re{n,m}` | 匹配 n 到 m 次（贪婪） |
| `a\|b` | 匹配 a 或 b |
| `(re)` | 分组，匹配括号内的表达式 |
| `(?P<name>...)` | 命名分组 |

### 预定义字符类

| 模式 | 描述 |
|------|------|
| `\w` | 匹配字母数字下划线 `[A-Za-z0-9_]` |
| `\W` | 匹配非字母数字下划线 |
| `\s` | 匹配任意空白字符 `[\t\n\r\f]` |
| `\S` | 匹配任意非空白字符 |
| `\d` | 匹配任意数字 `[0-9]` |
| `\D` | 匹配任意非数字 |
| `\b` | 匹配单词边界 |
| `\B` | 匹配非单词边界 |
| `\A` | 匹配字符串开始 |
| `\Z` | 匹配字符串结束（换行前） |
| `\z` | 匹配字符串结束 |

## 任务：日志解析器

编写一个名为 `log_parser.py` 的程序，在一个综合场景中运用正则表达式的各项功能。

> 本练习覆盖：`re.match()`、`re.search()`、`re.findall()`、`re.finditer()`、`re.sub()`、`re.split()`、`re.compile()`、分组捕获、标志位使用


### 场景描述

你有一份服务器访问日志，需要从中提取有用信息、进行数据清洗和格式转换。


### 具体要求

**1. 准备日志数据**

```python
log_data = """

192.168.1.2 - guest [01/Jan/2024:12:00:20 +0000] "GET /dashboard.html HTTP/1.1" 403 0
"""
```

**2. 提取所有 IP 地址（re.findall）**

- 使用 `re.findall()` 提取日志中所有的 IP 地址
- 打印去重后的 IP 列表

**3. 提取所有状态码（re.finditer）**

- 使用 `re.finditer()` 遍历所有 HTTP 状态码（200、404、403 等）
- 打印每个状态码及其在日志中的位置

**4. 提取请求方法和路径（re.search + 分组）**

- 对每行日志使用 `re.search()` 提取请求方法（GET/POST）和请求路径
- 使用分组捕获，打印 `"方法: GET, 路径: /index.html"` 格式

**5. 替换敏感信息（re.sub）**

- 将日志中的 IP 地址替换为 `"***"`（保留格式）
- 打印替换后的日志

**6. 分割日志字段（re.split）**

- 使用 `re.split()` 按空格或 `-` 分割日志行
- 提取每行的用户名字段（第 3 个字段）

**7. 编译正则表达式（re.compile）**

- 使用 `re.compile()` 编译一个用于匹配完整日志行的正则表达式
- 使用编译后的对象提取每行的：IP、用户名、日期、请求方法、路径、状态码、响应大小

**8. 统计分析（综合应用）**

- 统计每种状态码的出现次数
- 统计每个 IP 的请求次数

print("\n=== 3. 提取请求方法和路径 ===")
