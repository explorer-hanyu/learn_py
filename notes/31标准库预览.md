# Python3 标准库概览 笔记

## 一、概述

Python 标准库非常庞大，所提供的组件涉及范围十分广泛，使用标准库可以让我们轻松地完成各种任务。

以下是一些 Python3 标准库中的核心模块：

| 模块 | 用途 |
|------|------|
| `os` | 操作系统交互（文件、目录、环境变量等） |
| `sys` | Python 解释器和系统相关功能 |
| `time` / `datetime` | 日期和时间处理 |
| `random` | 生成随机数 |
| `math` | 数学函数 |
| `re` | 正则表达式处理 |
| `json` | JSON 编码和解码 |
| `urllib` | 访问网页和处理 URL |


## 二、操作系统接口（os 模块）

`os` 模块提供了许多与操作系统交互的函数，例如创建、移动和删除文件和目录，以及访问环境变量等。

### 基本用法

```python
import os

# 获取当前工作目录
current_dir = os.getcwd()
print("当前工作目录:", current_dir)

# 列出目录下的文件
files = os.listdir(current_dir)
print("目录下的文件:", files)
```

### ⚠️ 注意事项

建议使用 `import os` 风格而非 `from os import *`，这样可以保证随操作系统不同而有所变化的 `os.open()` 不会覆盖内置函数 `open()`。

### 辅助工具

在使用 `os` 这样的大型模块时，内置的 `dir()` 和 `help()` 函数非常有用：

```python
import os
dir(os)    # 列出 os 模块中的所有可用函数和属性
help(os)   # 查看 os 模块的详细文档
```

### 高级文件操作（shutil 模块）

针对日常的文件和目录管理任务，`shutil` 模块提供了一个易于使用的高级接口：

```python
import shutil

# 复制文件
shutil.copyfile('data.db', 'archive.db')

# 移动文件/目录
shutil.move('/build/executables', 'installdir')
```


## 三、文件通配符（glob 模块）

`glob` 模块提供了一个函数用于从目录通配符搜索中生成文件列表：

```python
import glob

# 查找当前目录下所有 .py 文件
glob.glob('*.py')
# 输出: ['primes.py', 'random.py', 'quote.py']
```


## 四、命令行参数（sys 模块）

通用工具脚本经常调用命令行参数。这些命令行参数以链表形式存储于 `sys` 模块的 `argv` 变量中。

```python
import sys

# 命令行执行: python demo.py one two three
print(sys.argv)
# 输出: ['demo.py', 'one', 'two', 'three']
```

### 错误输出重定向和程序终止

`sys` 还有 `stdin`、`stdout` 和 `stderr` 属性，即使在 `stdout` 被重定向时，`stderr` 也可以用于显示警告和错误信息。

```python
import sys

# 输出错误信息到 stderr
sys.stderr.write('Warning, log file not found starting a new one\n')

# 终止程序
sys.exit()
```


## 五、字符串正则匹配（re 模块）

`re` 模块为高级字符串处理提供了正则表达式工具。对于复杂的匹配和处理，正则表达式提供了简洁、优化的解决方案。

```python
import re

# 查找所有以 f 开头的单词
re.findall(r'\bf[a-z]*', 'which foot or hand fell fastest')
# 输出: ['foot', 'fell', 'fastest']

# 替换重复的单词
re.sub(r'(\b[a-z]+) \1', r'\1', 'cat in the the hat')
# 输出: 'cat in the hat'
```

### ⚠️ 注意事项

如果只需要简单的功能，应该首先考虑字符串方法，因为它们非常简单，易于阅读和调试：

```python
# 简单的字符串替换，优先使用字符串方法
'tea for too'.replace('too', 'two')
# 输出: 'tea for two'
```


## 六、数学（math 模块）

`math` 模块为浮点运算提供了对底层 C 函数库的访问。

```python
import math

math.cos(math.pi / 4)
# 输出: 0.70710678118654757

math.log(1024, 2)
# 输出: 10.0
```


## 七、随机数（random 模块）

`random` 模块提供了生成随机数的工具。

```python
import random

# 从序列中随机选择一个元素
random.choice(['apple', 'pear', 'banana'])
# 输出: 'apple'

# 从 0-99 中随机抽取 10 个不重复的数字
random.sample(range(100), 10)
# 输出: [30, 83, 16, 4, 8, 81, 41, 50, 18, 33]

# 生成 0-1 之间的随机浮点数
random.random()
# 输出: 0.17970987693706186

# 从 range(6) 中随机选择一个整数（0-5）
random.randrange(6)
# 输出: 4
```


## 八、访问互联网（urllib 和 smtplib）

有几个模块用于访问互联网以及处理网络通信协议。其中最简单的两个是用于处理从 URLs 接收的数据的 `urllib.request` 以及用于发送电子邮件的 `smtplib`。

### urllib.request — 访问网页

```python
from urllib.request import urlopen

for line in urlopen('http://tycho.usno.navy.mil/cgi-bin/timer.pl'):
    line = line.decode('utf-8')  # 将二进制数据解码为文本
    if 'EST' in line or 'EDT' in line:
        print(line)
```

### smtplib — 发送邮件

```python
import smtplib

server = smtplib.SMTP('localhost')
server.sendmail('soothsayer@example.org', 'jcaesar@example.org',
    """To: jcaesar@example.org
    From: soothsayer@example.org
    Beware the Ides of March.
    """)
server.quit()
```

> **注意**：第二个例子需要本地有一个在运行的邮件服务器。


## 九、日期和时间（datetime 模块）

`datetime` 模块为日期和时间处理同时提供了简单和复杂的方法。支持日期和时间算法的同时，实现的重点放在更有效的处理和格式化输出。

### 基本用法

```python
import datetime

# 获取当前日期和时间
current_datetime = datetime.datetime.now()
print(current_datetime)
# 输出: 2023-07-17 18:37:56.036914

# 获取当前日期
current_date = datetime.date.today()
print(current_date)
# 输出: 2023-07-17

# 格式化日期
formatted_datetime = current_datetime.strftime("%Y-%m-%d %H:%M:%S")
print(formatted_datetime)
# 输出: 2023-07-17 18:37:56
```

### 日期计算

```python
from datetime import date

# 当前日期
now = date.today()
print(now)
# 输出: datetime.date(2023, 7, 17)

# 格式化日期
now.strftime("%m-%d-%y. %d %b %Y is a %A on the %d day of %B.")
# 输出: '07-17-23. 17 Jul 2023 is a Monday on the 17 day of July.'

# 计算年龄
birthday = date(1964, 7, 31)
age = now - birthday
print(age.days)   # 时间差的天数
# 输出: 21535
```


## 十、数据压缩

以下模块直接支持通用的数据打包和压缩格式：`zlib`、`gzip`、`bz2`、`zipfile` 以及 `tarfile`。

```python
import zlib

s = b'witch which has which witches wrist watch'
print(len(s))   # 41

t = zlib.compress(s)
print(len(t))   # 37

zlib.decompress(t)
# 输出: b'witch which has which witches wrist watch'

zlib.crc32(s)
# 输出: 226805979
```


## 十一、性能度量（timeit 模块）

有些用户对了解解决同一问题的不同方法之间的性能差异很感兴趣。Python 提供了一个度量工具 `timeit`，为这些问题提供了直接答案。

```python
from timeit import Timer

# 传统交换方式
Timer('t=a; a=b; b=t', 'a=1; b=2').timeit()
# 输出: 0.57535828626024577

# Python 的元组解包交换方式（更快）
Timer('a,b = b,a', 'a=1; b=2').timeit()
# 输出: 0.54962537085770791
```

> 相对于 `timeit` 的细粒度，`profile` 和 `pstats` 模块提供了针对更大代码块的时间度量工具。


## 十二、测试模块（doctest 和 unittest）

### doctest — 文档测试

`doctest` 模块提供了一个工具，扫描模块并根据程序中内嵌的文档字符串执行测试。测试构造如同简单地将它的输出结果剪切并粘贴到文档字符串中。

```python
def average(values):
    """Computes the arithmetic mean of a list of numbers.

    >>> print(average([20, 30, 70]))
    40.0
    """
    return sum(values) / len(values)

import doctest
doctest.testmod()   # 自动验证嵌入测试
```

### unittest — 单元测试

`unittest` 模块不像 `doctest` 模块那么容易使用，不过它可以在一个独立的文件里提供一个更全面的测试集。

```python
import unittest

class TestStatisticalFunctions(unittest.TestCase):
    def test_average(self):
        self.assertEqual(average([20, 30, 70]), 40.0)
        self.assertEqual(round(average([1, 5, 7]), 1), 4.3)
        self.assertRaises(ZeroDivisionError, average, [])
        self.assertRaises(TypeError, average, 20, 30, 70)

unittest.main()   # 从命令行调用会执行所有测试
```
