# Python3 命名空间和作用域 笔记

## 一、命名空间（Namespace）

### 1.1 什么是命名空间

命名空间是从**名称到对象的映射**，大部分的命名空间都是通过 Python 字典来实现的。

命名空间提供了在项目中**避免名字冲突**的一种方法。各个命名空间是独立的，没有任何关系的，所以一个命名空间中不能有重名，但**不同的命名空间是可以重名而没有任何影响**。

> 类比：一个文件夹中可以包含多个文件夹，每个文件夹中不能有相同的文件名，但不同文件夹中的文件可以重名。

### 1.2 三种命名空间

| 命名空间 | 说明 | 示例 |
|----------|------|------|
| **内置名称（Built-in names）** | Python 语言内置的名称 | `abs`、`print`、`Exception` 等 |
| **全局名称（Global names）** | 模块中定义的名称，记录了模块的变量、函数、类、导入的模块等 | 模块级变量、函数定义 |
| **局部名称（Local names）** | 函数中定义的名称，记录了函数的参数和局部定义的变量 | 函数内的变量、参数 |

### 1.3 命名空间的查找顺序

当使用一个变量时，Python 的查找顺序为：

```
局部命名空间 → 全局命名空间 → 内置命名空间
```

如果找不到该变量，将引发 `NameError` 异常。

### 1.4 命名空间的生命周期

命名空间的生命周期取决于对象的**作用域**。如果对象执行完成，则该命名空间的生命周期就结束。因此，**无法从外部命名空间访问内部命名空间的对象**。


## 二、作用域（Scope）

### 2.1 什么是作用域

作用域就是一个 Python 程序可以**直接访问命名空间的正文区域**。

在一个 Python 程序中，直接访问一个变量，会**从内到外**依次访问所有的作用域直到找到，否则会报未定义的错误。

变量的作用域决定了在哪一部分程序可以访问哪个特定的变量名称。

### 2.2 四种作用域（LEGB 规则）

Python 的作用域一共有 4 种，按照**查找顺序**排列：

| 缩写 | 名称 | 说明 | 查找优先级 |
|------|------|------|------------|
| **L** | Local（局部） | 最内层，包含局部变量，比如一个函数/方法内部 | **第1优先** |
| **E** | Enclosing（嵌套） | 包含了非局部也非全局的变量。比如两个嵌套函数，外层函数的作用域 | **第2优先** |
| **G** | Global（全局） | 当前脚本的最外层，比如当前模块的全局变量 | **第3优先** |
| **B** | Built-in（内置） | 包含了内建的变量/关键字等 | **最后搜索** |

**LEGB 规则**：Python 查找变量时的顺序是 **L → E → G → B**。

### 2.3 哪些代码块会引入新的作用域

**Python 中只有模块（module）、类（class）以及函数（def、lambda）才会引入新的作用域**。

**其他代码块（如 `if/elif/else`、`try/except`、`for/while` 等）不会引入新的作用域**，这些语句内定义的变量，外部也可以访问。

```python
# if 语句块不会引入新作用域
if True:
    msg = 'I am from Runoob'
print(msg)  # 输出: I am from Runoob

# 函数会引入新作用域
def test():
    msg_inner = 'I am from Runoob'
print(msg_inner)  # NameError: name 'msg_inner' is not defined
```


## 三、全局变量与局部变量

### 3.1 基本概念

| 类型 | 定义位置 | 作用范围 |
|------|----------|----------|
| **全局变量** | 函数外部定义 | 在整个程序范围内可以访问 |
| **局部变量** | 函数内部定义 | 只能在函数内部访问 |

### 3.2 局部变量优先级高于全局变量

函数内部声明的变量只在函数内部的作用域中有效，**不会影响到函数外部的同名变量**。

```python
total = 0          # 全局变量

def sum(arg1, arg2):
    total = arg1 + arg2   # 局部变量，与全局变量同名
    print("函数内是局部变量 : ", total)   # 输出: 30
    return total

sum(10, 20)
print("函数外是全局变量 : ", total)   # 输出: 0
```

### 3.3 在函数内访问全局变量

```python
x = 10             # 全局变量
def my_function():
    print(x)       # 可以访问全局变量 x
my_function()      # 输出: 10
```


## 四、global 和 nonlocal 关键字

### 4.1 global —— 修改全局变量

当内部作用域想**修改**外部作用域的变量时，就要用到 `global` 和 `nonlocal` 关键字了。

在函数内部修改全局变量，需要使用 `global` 关键字声明：

```python
num = 1
def fun1():
    global num     # 需要使用 global 关键字声明
    print(num)     # 输出: 1
    num = 123
    print(num)     # 输出: 123

fun1()
print(num)         # 输出: 123
```

### 4.2 nonlocal —— 修改嵌套作用域变量

如果要修改**嵌套作用域（enclosing 作用域，外层非全局作用域）** 中的变量，则需要 `nonlocal` 关键字：

```python
def outer():
    num = 10
    def inner():
        nonlocal num   # nonlocal 关键字声明
        num = 100
        print(num)     # 输出: 100
    inner()
    print(num)         # 输出: 100

outer()
```

### 4.3 ⚠️ 常见陷阱：UnboundLocalError

```python
a = 10
def test():
    a = a + 1    # 错误：局部变量 'a' 在赋值前被引用
    print(a)
test()
```

报错：`UnboundLocalError: local variable 'a' referenced before assignment`

**原因**：在函数内部，如果对一个变量进行**赋值**操作，Python 会将其视为**局部变量**。此时 `a = a + 1` 右侧的 `a` 被认为是局部变量，但尚未定义，因此报错。

**解决方法**：使用 `global` 关键字声明：

```python
a = 10
def test():
    global a
    a = a + 1
    print(a)   # 输出: 11
test()
```


## 五、重点总结

| 知识点 | 要点 |
|--------|------|
| **命名空间** | 名称到对象的映射，用字典实现，避免命名冲突 |
| **三种命名空间** | 内置（Built-in）、全局（Global）、局部（Local） |
| **查找顺序** | 局部 → 全局 → 内置 |
| **LEGB 规则** | Local → Enclosing → Global → Built-in |
| **引入新作用域** | 只有模块、类、函数会引入新作用域 |
| **全局变量** | 函数外定义，整个程序可访问 |
| **局部变量** | 函数内定义，仅函数内可访问 |
| **global** | 在函数内修改全局变量时使用 |
| **nonlocal** | 在嵌套函数中修改外层（非全局）变量时使用 |
| **UnboundLocalError** | 函数内对变量赋值会使其成为局部变量，注意与全局变量同名时的陷阱 |

# 📝 综合练习题

## 任务：嵌套计数器系统

编写一个名为 `counter_system.py` 的程序，综合运用命名空间与作用域的知识，理解 LEGB 查找规则以及 `global` 和 `nonlocal` 的使用场景。

> 本练习覆盖：LEGB 查找顺序、全局变量与局部变量、`global` 关键字、`nonlocal` 关键字、嵌套函数、`UnboundLocalError` 的理解


#### 场景描述

你需要开发一个**多层计数器系统**，包含全局计数器、外层函数计数器和内层函数计数器，通过嵌套函数来展示不同作用域中变量的访问和修改规则。


### 具体要求

**1. 基础变量定义（理解作用域层级）**

定义以下变量：
- 全局变量 `global_counter = 0`
- 定义函数 `outer()`，在其内部定义 `outer_counter = 0`
- 在 `outer()` 内部定义函数 `inner()`，在其内部定义 `inner_counter = 0`

在 `inner()` 中分别**读取**并打印三个计数器的值（不修改），观察 LEGB 查找顺序。

**2. 使用 global 修改全局变量**

在 `inner()` 中：
- 使用 `global` 关键字声明 `global_counter`
- 将 `global_counter` 加 1
- 打印修改后的值

**3. 使用 nonlocal 修改外层变量**

在 `inner()` 中：
- 使用 `nonlocal` 关键字声明 `outer_counter`
- 将 `outer_counter` 加 1
- 打印修改后的值

**4. 局部变量修改（不加关键字）**

在 `inner()` 中：
- 直接修改 `inner_counter += 1`（不加任何关键字）
- 打印修改后的值

**5. 观察 UnboundLocalError**

在 `outer()` 中定义一个函数 `test_unbound()`：
- 尝试执行 `global_counter = global_counter + 1`（不加 `global` 声明）
- 运行并观察报错信息，在代码中用注释解释原因

**6. 综合调用与输出**

按以下顺序执行：
1. 调用 `inner()` 三次，观察三个计数器的变化
2. 打印全局变量、外层变量、内层变量的最终值
3. 用注释说明每次修改分别使用了什么关键字


### 代码框架（填空版）

```python
# ========== 1. 定义变量和嵌套函数 ==========
global_counter = 0          # 全局变量

def outer():
    outer_counter = 0       # 外层函数变量（enclosing）
    print(f"[outer] 初始 outer_counter = {outer_counter}")

    def inner():
        inner_counter = 0   # 内层函数变量（local）
        print(f"\n[inner] 初始值: global={global_counter}, outer={outer_counter}, inner={inner_counter}")

        # ========== 2. 修改全局变量 ==========
        ______ global_counter   # 填空：global 声明
        global_counter ______ 1   # 填空：自增
        print(f"[inner] 修改后 global = {global_counter}")

        # ========== 3. 修改外层变量 ==========
        ______ outer_counter   # 填空：nonlocal 声明
        outer_counter ______ 1   # 填空：自增
        print(f"[inner] 修改后 outer = {outer_counter}")

        # ========== 4. 修改局部变量 ==========
        inner_counter ______ 1   # 填空：自增（不加关键字）
        print(f"[inner] 修改后 inner = {inner_counter}")

        return outer_counter, inner_counter

    # ========== 5. 观察 UnboundLocalError ==========
    def test_unbound():
        # 下面的代码会报错，因为 global_counter 被赋值，
        # Python 将其视为局部变量，但赋值前又被引用
        # global_counter = global_counter + 1  # 取消注释会报 UnboundLocalError
        pass

    return inner

# ========== 6. 执行测试 ==========
if __name__ == "__main__":
    print("=" * 40)
    print("嵌套计数器系统")
    print("=" * 40)

    inner_func = outer()

    # 调用 inner 三次
    for i in range(3):
        print(f"\n--- 第 {i+1} 次调用 inner ---")
        inner_func()

    print("\n" + "=" * 40)
    print("最终结果")
    print("=" * 40)
    print(f"global_counter = {global_counter}")
    # 注意：outer_counter 和 inner_counter 是局部变量，无法从外部访问
    # 只能通过函数返回值获取，这里演示作用域的限制
```


### 预期输出示例

```
========================================
嵌套计数器系统
========================================
[outer] 初始 outer_counter = 0

[inner] 初始值: global=0, outer=0, inner=0
[inner] 修改后 global = 1
[inner] 修改后 outer = 1
[inner] 修改后 inner = 1

--- 第 2 次调用 inner ---
[inner] 初始值: global=1, outer=1, inner=0
[inner] 修改后 global = 2
[inner] 修改后 outer = 2
[inner] 修改后 inner = 1

--- 第 3 次调用 inner ---
[inner] 初始值: global=2, outer=2, inner=0
[inner] 修改后 global = 3
[inner] 修改后 outer = 3
[inner] 修改后 inner = 1

========================================
最终结果
========================================
global_counter = 3
```

> **关键观察**：
> - `global_counter` 使用 `global` 声明，每次调用都在**全局范围**累加 → 最终为 3
> - `outer_counter` 使用 `nonlocal` 声明，每次调用都在**外层函数范围**累加 → 最终为 3
> - `inner_counter` 是**局部变量**，每次调用 `inner()` 都会重新初始化为 0 → 每次都是 1
> - 三种不同的作用域，三种不同的行为！
